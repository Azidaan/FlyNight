# Определения стресс-поднаборов BDD100K MOT

Зафиксировано 2026-07-02 (Этап 2). Ведущий источник определений в коде —
`datasets/subset_filter.py` (SUBSET_DEFINITIONS/_PREDICATES); этот документ —
человекочитаемая копия для текста диссертации (раздел 2.3).

## Источник тэгов

Тэги weather/timeofday лежат в **per-image Det-лейблах**
(`labels/bdd100k_labels_images_{train,val}.json`), а не в MOT-аннотациях
box_track_20 (там их нет — проверено smoke-тестом). Сопоставление:
`video_id == os.path.splitext(entry['name'])[0]`. Покрытие: **1400/1400 train,
200/200 val** (подтверждено `scripts/test_subsets.py`).

## Определения

| Поднабор | Условие | train: видео / кадров | val: видео / кадров |
|----------|---------|------------------------|----------------------|
| Normal | timeofday == daytime И weather == clear | 274 / 55 050 | 36 / 7 190 |
| Night | timeofday == night (любая погода) | 564 / 111 895 | 71 / 14 265 |
| Rain | weather == rainy (любое время суток) | 85 / 16 376 | 16 / 3 142 |
| Fog | weather ∈ {foggy, overcast} | 197 / 39 437 | 26 / 5 257 |

Поднаборы пересекаются (например, ночной дождь попадает и в Night, и в Rain) —
это осознанно: каждый поднабор отвечает на свой вопрос об устойчивости.

## Обоснование расширенного Fog

С тэгом `weather == foggy` в BDD100K ровно 1 train-видео и 0 val — узкое
определение статистически невалидно. Поэтому Fog с самого начала задан как
{foggy, overcast} (План Б из Части 2.9 применён превентивно). Это ограничение
источника данных фиксируется в диссертации честно.

## Порог достаточности

Критерий плана: train-поднабор < 50 видео — кандидат на расширение определения.
По факту минимальный поднабор (Rain, 85 видео / 16 376 кадров) выше порога —
расширение не требуется. Val Rain (16 видео) мал, но валидация идёт по кадрам
(3 142 кадра) и по полным видео для трекинга — приемлемо; при необходимости
доверительные интервалы по Rain обсуждаются в тексте.

## Классы (MOT box_track_20 — 8 категорий)

`pedestrian:0, rider:1, car:2, truck:3, bus:4, train:5, motorcycle:6, bicycle:7`
(порядок официальный BDD100K MOT; маппинг — `datasets/format_converter.py`).
В Det-таксономии BDD100K 10 классов, но в MOT-аннотациях traffic light /
traffic sign отсутствуют — обучение и оценка детектора в работе идут на
8 классах MOT. Рамки с `attributes.crowd == true` пропускаются (ignore-регионы
официального протокола); неизвестные категории логируются при конвертации
(`notes/conversion_stats.json`).
