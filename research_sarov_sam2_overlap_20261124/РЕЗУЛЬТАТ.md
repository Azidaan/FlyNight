# Две машины в перекрытии. Что меняет один предыдущий кадр

В видео BDD100K `b242f6b2-f5da110f` геометрический прогноз и небольшой трансформер на кадре 172 поменяли местами две машины. Среди двух проверочных групп по 20 видео это единственный переход, на котором оба метода одновременно присвоили каждой машине рамку другой. Эпизод выбран по известной ошибке. [Правило отбора](protocol.json)

## 1. С какого кадра начать сопровождение

Локальная SAM 2.1 Hiera Tiny получила по одной прошлой рамке YOLO26s для каждой машины. Прошлая разметка указывала, какой машине принадлежит каждая рамка. Для каждого номера отдельно велась память. На кадре 172 прогнозы сравнивались со всеми 14 масками, полученными по текущим рамкам YOLO. Номер присваивался при единственном взаимно лучшем совпадении выше 0,5. Сходство масок измерялось отношением площади пересечения к площади объединения. [Протокол парного сравнения](earlier_protocol.json)

При старте с кадра 171 маски двух машин перекрывались на 77,9%, а на кадре 172 перекрытие прогнозов достигло 96,0%. Прогноз машины А совпал со своей текущей маской на 54,0%, с маской Б на 63,1%. Прогноз Б тоже выбрал Б, с совпадением 65,7%. Номер Б получил правильную рамку, номер А ожидал. Результат сохранился при сравнении только двух спорных рамок. [Все оценки первого опыта](result.json)

При старте с кадра 170 обе машины наблюдались ещё на одном предыдущем кадре. Перекрытие их исходных масок составило 5,6%, на кадре 171 оно составляло 7,8%, на кадре 172 — 20,0%. На этом последнем кадре совпадение прогноза А со своей текущей маской достигло 90,3%, прогноза Б со своей — 92,5%. Среди тех же 14 кандидатов оба номера получили правильные рамки. Дополнительных подсказок после начальных рамок не было. [Все оценки парного опыта](earlier_result.json)

На этом переходе причина ожидания установлена на уровне назначения. Оба прогноза предпочли рамку Б. Изменения только момента инициализации памяти хватило для восстановления обоих соответствий. Вклад конкретного слоя модели и точность пиксельных границ относительно ручной разметки здесь не измерялись. Для проверки переноса нужны другие видео с перекрытием. [Сравнение масок на кадре 172](compare_172.jpg)

## 2. Проверка воспроизводимости

В первой попытке контроль начинался со второго внутреннего кадра трёхкадрового клипа. Начальные маски совпали с сохранёнными, а у перенесённых обнаружилось различие. Этот прогон исключён. При повторе каждой паре начальных рамок соответствовало начало своего клипа. Для контроля в точности воспроизведены пиксели исходных и перенесённых масок, обе текущие маски и все 28 оценок сходства. Контрольные суммы снимались до расчёта, затем входы проверялись повторно. [Журнал исправления](earlier_control_retry.json) · [Входы парного опыта](earlier_inputs.json)

## 3. Решение о SAM 3D Objects

Направление SAM 3D Objects закрыто для текущего стенда по стоимости покадровой облачной обработки и требованиям штатной локальной реализации. Качество реконструкции на кадрах проекта осталось неизмеренным. Локальные опыты SAM 2 продолжаются. [Инструкция Meta](https://github.com/facebookresearch/sam-3d-objects/blob/main/doc/setup.md) · [Тариф облачной реконструкции](https://fal.ai/models/fal-ai/sam-3/3d-objects)
