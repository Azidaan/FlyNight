# Ночная лавка зелий

Пошаговая игра про торговлю зельями ночью под дождём. Главная механика — трекинг:
ты видишь сцену, но кто есть кто знаешь только со слов трекера. Погода роняет
уверенность, рамки теряются, а иногда ID двух рыцарей меняются местами — и игра
об этом не сообщает.

## Запуск

    powershell -File tools\fetch_godot.ps1     # один раз, качает движок
    engine\Godot.exe --path .                  # запустить игру
    engine\Godot.exe --headless --path . --script res://tests/run_all.gd

Движок: Godot 4.7.1 stable. Версия зафиксирована, не обновлять без проверки.

## Устройство

Три слоя, ничего не знающих друг о друге:

- `src/world/` — состояние и правила. Чистый GDScript на `RefCounted`, ни одной ноды.
- `src/tracking/` — источник рамок за интерфейсом `TrackSource`. Сейчас `FakeTracker`
  считает деградацию по формулам; позже сюда встанет настоящий YOLO.
- `src/view/` — Godot. Подписан на события мира, ничего не решает.
