# Атлас FlyVis

Откройте `dist/index.html` двойным щелчком, чтобы посмотреть сохранённые эпизоды, или `START.cmd`, чтобы открыть атлас с обработкой своего файла. Во втором случае браузер открывается на свободном порту адреса 127.0.0.1. Чтобы завершить сервер, нажмите Ctrl+C в его окне. Интернет для работы не нужен.

## Первый маршрут

Начните с эпизода «0199e7fc · кадр 212». Слева показан настоящий кадр; кнопка увеличения приближает область, которую получил глаз модели. Вторая панель показывает 721 значение яркости. На шаге «Карта клеток» выберите T4a или другой тип и нажмите на интересующее место. Для 34 типов доступны численные карты. На шаге выбора переключите «Вся рамка» на «Только свои»: изменится ответ. Это совпадает с архивным измерением.

«Тип клетки» и «место в изображении» — разные вещи. В коннектоме этой модели 65 типов. T4 и T5 — семейства; T4a–d и T5a–d — восемь направленных подтипов. Страница «Архитектура» показывает их входящие и исходящие связи по файлу коннектома. Величина связи в схеме суммирует контакты в пространственном шаблоне типа; она не измеряет полезность клетки для трекинга.

Пять демонстрационных эпизодов выбраны из предыдущего опыта именно потому, что при исключении общей части рамок выбор менялся; по ним нельзя оценивать среднюю точность. В них 51 архивный шаг и 48 разных локальных изображений: в начале некоторых последовательностей кадр повторяется. Карты сохранены для восьми моментов, остальные доступны как вход глаза. Картинки уменьшены для показа; при научном расчёте использованы прежние входы и состояния.

## Свой файл

Во вкладке «Свой файл» браузер формирует из середины изображения квадрат 256 × 256. Для видео обрабатывается начало — до 12 кадров с шагом 1/30 с. В локальный вычислитель передаются только эти кадры в оттенках серого. BoxEye формирует вход; FlyVis со штатными весами flow/0000/000 на процессоре возвращает исходную активность. На первом кадре используется плавное введение стимула, затем состояние продолжается. Для отдельного фото нет наблюдаемого движения. Шкала сырых откликов своего файла отличается от нормированной архивной карты. Рамки и метки личности для произвольного файла не строятся.

Вычислитель принимает одну задачу одновременно; отдельный контроллер следит за системной памятью. Во время вычисления научной серии он может отказать в запуске. Исходное пользовательское видео не записывается. Временные данные запроса удаляются при нормальном завершении. Сервер доступен только на компьютере пользователя.

## Откуда взялись результаты

В разделе «Проверки» раздельно показаны 65 вмешательств в состояние сети перед последним кадром и 34 вмешательства в прямые выходные каналы. Колонки — отдельная пространственная проверка только при считывании. Все выводы относятся к одному замороженному считывателю и 172 сохранённым парам. Выигрыш на этих парах сам по себе не означает улучшения полных траекторий.
