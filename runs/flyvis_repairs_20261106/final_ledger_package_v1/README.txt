1. Состав записи

В журнал и каталог входят только четыре карточки и пять блоков этого аудита поверх проверенного исходного коммита. Остальные пользовательские записи остаются в рабочих файлах и не включаются этим пакетом. Канонические версии двух документов берутся из проверенной audit_ledger_overlay_v2, а не из полного рабочего дерева.

2. Изоляция Git

Пакет предназначен для prepare_private_ledger_commit.py: отдельный индекс, неизменяемые объекты Git, commit-tree с зафиксированным родителем и создание нового refs/codex/audit-ledger-20261107 без замены существующей ссылки. Текущая ветка, общий индекс и рабочие документы не изменяются. Полные локальные временные копии и приватный индекс не публикуются. Публикация GitLab использует только изменённые файлы; чужой исследовательский коммит не переносится.

3. Сохранность доказательств

Виртуальная версия runs/.gitattributes сохраняет все прежние строки и добавляет только точные правила -text для новых артефактов. Сам рабочий файл атрибутов не заменяется. Это обеспечивает сохранение байтов патчей и журналов после публикации. manifest.json хешируется внешним аргументом команды, остальные строки содержат точные SHA256, размеры и исходные объекты Git.

4. Проверки и границы

Штатный валидатор и 58 тестов прошли в полном рабочем каталоге и в изолированном представлении V2. Два старых предупреждения о шаблонных путях сохранены. Это запись технического результата; новой оценки HOTA нет. Идентификаторы фактического локального и удалённого коммитов и проверка публикации записываются отдельным последующим подтверждением.
