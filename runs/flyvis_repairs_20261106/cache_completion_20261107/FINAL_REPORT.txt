Проверка кэша истории и допуск седьмого пакета, 07.11.2026

Исправлено сохранение временных путей рабочего дерева в кэше истории. Постоянные события сохраняются, статистика кэша соответствует сохранённым событиям, обычное отображение и восстановление актуального состояния Git проверены. Адресное воспроизведение до исправления: один отказ и одна успешная проверка; после исправления обе проверки прошли (memory_incident_20261107/cache_before_v2 и cache_after).

Все 58 прежних тестов истории и два новых теста пройдены для рабочего проекта и для точного представления документов публикации. Наиболее затратный тест выполнялся отдельным процессом, остальные 59 вместе; пропусков нет, выбранные группы не пересекаются. Валидатор публикации завершился успешно; два прежних предупреждения о шаблонных путях старой карточки сохранены. Источник: acceptance.json и publication_gate.json с адресами отдельных журналов.

Все новые проверки запускались последовательно с запросом ограничения Windows Job 512 МиБ. Максимальный измеренный пик группы среди этих успешных проверок — 517287936 байтов. Предыдущие MemoryError, тайм-ауты и прерванные запуски сохранены отдельно; они не переименованы в успешные.

Присланное окно аварии Python не удалось сопоставить с PID. Отдельный тест кэша завершился штатно, код возврата 0; причина окна и прежней перезагрузки остаётся неустановленной. Это исправление не гарантирует ограничение памяти при первом чтении прежних больших кэшей; полный захват вывода Git также остаётся отдельным риском.

Исходники остальных исправлений седьмого пакета совпали с их проверенными контрольными суммами. Сохранены результаты совместного прогона 822 passed, 2 skipped до изменения кэша истории; новый кэш проверен отдельно описанными тестами. Обучение, HOTA и изменение штатных весов не выполнялись.
