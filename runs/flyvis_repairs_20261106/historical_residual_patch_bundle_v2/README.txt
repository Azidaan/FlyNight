1. Содержание и граница публикации

Пакет содержит только собственные изменения двух ранее существовавших untracked исходников, два новых теста в виде patches, отчеты и журналы проверок. Полные пользовательские исходники, веса, массивы нейронной активности, рабочие копии и снимки зависимостей сюда не включены. Тесты остаются patches, чтобы частичная публикация не добавляла исполняемые тесты без нужного пользовательского окружения.

2. Что проверено

deterministic_call восстанавливает enabled и warn_only; 14failed/6passed до, 21passed после. Historical ResidualEngine проверяет вход и кандидат состояния/активности до публикации в eye; 44failed/5passed до, 74passed после. Настоящие R1 и имеющиеся B/C/D weights на CPU дали побитное совпадение допустимых выходов до/после и точный повтор после отклонения отказа. Независимый reviewer дополнительно подтвердил NaN в несчитываемом нейроне настоящего C/D, исключение wrapped backend, сохранение флагов и точный повтор. CUDA не инициализировалась. Эти проверки не измеряют HOTA или скорость GPU.

3. Точное применение и отмена

manifest.json содержит исходные/конечные SHA256, обязательное отсутствие новых тестов перед применением, порядок patches и точные команды. Применять следует только к точному исходному состоянию: при несовпадении SHA256 остановиться, не использовать fuzz/offset как доказательство совместимости. Все файлы UTF-8/LF; параметр -c core.autocrlf=false обязателен, чтобы настройка Git не меняла байты новых файлов. После применения проверить конечные SHA256. Для отмены нужны именно конечные SHA256, затем reverse в обратном порядке; оба новых теста должны исчезнуть, два исходных файла восстановиться побайтно.

Команды в manifest рассчитаны на cwd корня целевой копии проекта и не используют --index или --cached. Пакет проверен через git apply только на временной копии вне области обнаружения репозитория: apply/reverse подтвердили все четыре конечные и исходные состояния. Индекс и Git metadata проекта не менялись. Текущие production-файлы уже исправлены, поэтому к ним повторно применять пакет не требуется. Не запускать reverse на них во время общего тестирования.

4. Пределы

Атомарно обновляется eye относительно функциональных штатных backend. Произвольная запись стороннего backend в старый тензор не откатывается. Нет общей транзакции всего Tracker.update или отката успешного advance при последующей ошибке головы/MASA. Временная политика historical моделей и веса не изменены. Для запуска тестов нужен исходный проект с его зависимостями; пакет намеренно не является автономной поставкой исходного проекта.
