# 🟢 Что мешает сшивке обрывков: голова узнавания или окна поиска кандидатов (идеальная сшивка внутри окон)

↑ [[01 Муха/Темы/Прочее о мухе|Прочее о мухе]] · **Исход:** положительный · `fly_stitch_oracle_v1`

Склейка обрывков — до +6,1 HOTA на test (fly_assoc_target_v1), сшивка по геометрии берёт +0,84. scripts/fly_stitch_oracle.py: идеальная сшивка (только настоящие пары по эталону) среди кандидатов окон (разрыв ≤ 60 кадров, ≤ 3 размеров рамки — нынешнее), (150; 5), (300; 8); тот же жадный сшиватель; HOTA test 35 и val7.

## Вопрос
Ограничивает ли сшивку голова узнавания или окна поиска кандидатов?

## Гипотеза
В нынешнем окне идеальная сшивка берёт заметную часть запаса склейки; расширение окон даёт ещё.

## Ожидалось (до прогона)
Если идеальная сшивка в нынешнем окне ≥ +3 HOTA — главное — голова узнавания (мишень для признаков мухи и внешности); если < +2 и растёт с окном — главное — окна поиска.

## Получено
runs/fly_stitch_oracle/summary.json: идеальная сшивка (только настоящие пары) Δ HOTA к стенду — gap60_dist3: test 2,267 [1,704; 2,898], val7 2,090, кандидатов test 32178 (настоящих 4712); gap150_dist5: test 2,975 [2,257; 3,733], val7 2,590, кандидатов test 102894 (настоящих 8383); gap300_dist8: test 3,113 [2,404; 3,926], val7 3,454, кандидатов test 253502 (настоящих 12171).

## Интерпретация
В нынешнем окне голова узнавания берёт +0,84 из доступных +2,27 (37 %) — главное узкое место — голова; расширение окна добавляет доступного запаса +0,7 (150; 5) и +0,85 (300; 8) на test. Остаток до склейки (+6,1) — обрывки без сопоставления концов на размеченных кадрах и цепочки с общими кадрами (их сшиватель запрещает).

## Решение
Критерий выполнен (+2,27 ≥ … нет: < +3) — формально узкое место смешанное: голова (37 % от доступного в окне) и окно. Шаги: (1) сшивка в окне (150; 5) с нынешней головой (fly_stitch_window_v1); (2) голова сильнее — признаки внешности из работ по повторному опознанию (замена узла «внешность»: сейчас косинус миниатюры и гистограмма) — загрузка весов по согласованию.

## Условия
- **baseline:** стенд как есть
- **variant:** идеальная сшивка в окнах
- **dataset:** BDD100K MOT train_cache test 35 + val7

## Критерии приёмки (записаны до прогона)
