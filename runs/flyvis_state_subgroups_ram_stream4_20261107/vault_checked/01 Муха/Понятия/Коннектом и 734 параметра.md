# Коннектом и 734 параметра

↑ [[01 Муха/Муха (FlyVis)|Муха]]

Схема связей (коннектом) фиксирована: какие типы нейронов с какими соединены, знак и число синапсов. Обучаются 734 числа: 65 постоянных времени, 65 потенциалов покоя, 604 силы связей «тип → тип». Поэтому любое дообучение остаётся «мушиным» по устройству, но может потерять «мушиность» по работе — её проверяют сравнением с биологией (`dsi_correlation_to_known`, `fri_correlation_to_known` в flyvis).

Откуда схема: 1 801 нейрон старых реконструкций (FIB-25 — 7 колонок медуллы, FIB-19), усреднённых по парам типов. Полная зрительная доля есть в FlyWire — задумка К16 в блоке «Запланировано» (↗ «FlyWire — донор анатомии (К16)»).
