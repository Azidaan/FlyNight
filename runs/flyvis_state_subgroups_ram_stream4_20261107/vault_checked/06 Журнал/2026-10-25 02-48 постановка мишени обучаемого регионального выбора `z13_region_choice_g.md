# 2026-10-25 02:48 — постановка мишени обучаемого регионального выбора `z13_region_choice_gate_v1`

↑ [[06 Журнал/Дни/2026-10-25|2026-10-25]]

*Действие.* Replace coordinate-only output by a learned target-conditional categorical choice among actual high-score same-class detection regions in the eye and NULL. Before feature extraction/training, test whether this expressible output has additional useful assignment reserve over the failed three-peak center action.

*Механизм.* For each unchanged tracker row: original cost vector, NULL vector all1, and each visible same-class region with one-hot probability1. With the unchanged cost=1-det_conf*prob interface, chosen cost=1-det_conf, every other cost1. Solve the whole original assignment. Extreme distributions are only an optimistic diagnostic of that interface. No true identity, target box or query outcome enters action generation.

*Критерий.* Mean-video any-beneficial reserve>=0.02 and its lower95%paired-videoCI>0, plus categorical-reserve minus Dthreepeak-reserve lower95%paired-videoCI>0. Failing gate stops this specific output interface before learned feature extraction. Passing only warrants registration of a matched learned region head; it is not FlyVis benefit or HOTA.

*Отличие от испытанного.* The old detection3 gate measured center accuracy. The failed region_readout used a fixed mean of an existing response map. The new proposed learner would compare raw target-conditioned activity at actual detection regions, with competition and NULL. This gate tests its action space only, before building that learner; it does not rescue failed fixed pooling or repeat a three-peak ranker.

*Возражение.* An oracle can exploit detections without a fly; the real readout may not distinguish them. One-row shadow choices omit feedback, simultaneous interventions and subsequent association stages. One-hot probabilities are optimistic extremes. A larger reserve is necessary for this proposed implementation, not sufficient for training success or scientific novelty.

CPU600с+20с, один независимый контроллер и видимая консоль. SiamMOT https://arxiv.org/html/2105.11595v1 sections3,5: region-based target-conditional motion for matching; our categorical interface and reserve gate are adaptations, not its published numbers.
