# 3.8. WTConv по первоисточникам (сверено 07.09)

↑ [[05 План/3. Все измеренные числа|3. Все измеренные числа]]

Репозиторий `github.com/BGU-CS-VIL/WTConv`, лицензия MIT; базис — параметр
конструктора (`wt_type`, фильтры через pywt), есть `wtconv1d.py` и папка
`fast_wtconv`.

| задача (ImageNet-1K, 300 эпох) | база | с WTConv | % |
|---|---|---|---|
| классификация ConvNeXt-T | 82.1 | 82.5 | +0.5% |
| сегментация ADE20K, mIoU | 46.0 | 46.6 | +1.3% |
| детекция COCO, AP box | 47.3 | 47.9 | +1.3% |
| устойчивость ImageNet-C̄ (ошибка) | 40.0 | 38.0 | −5.0% |

**Абляция базисов у авторов уже проведена:** Haar 81.75, db2 81.68, db3 81.56.
Хаар лучший. У нас на траекториях порядок обратный — Хаар худший. Домены разные.

**Быстрая реализация написана только под Хаара** (ядра `cuda_haar`,
`triton_haar`, оптимизация построена на «бабочке Хаара»): со сменой базиса
несовместима. Ускорение 4.35× и половинный пик памяти — из отдельной работы
arXiv:2608.10805, а не из README самого репозитория (там 2.3–3.0×).
