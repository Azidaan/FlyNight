# Проверить признаки MASA в реальных назначениях трекера

[[Обзор проекта/Запланировано|Запланировано]]

**Новое действие.** Заменить извлекатель, обученный на людях, на уже имеющийся MASA для разных классов объектов. Правило спорного назначения, детекции и остальной трекер сохраняются. Признаки получают из текущего полного кадра и реальных областей и сохраняют до перехода к следующему кадру. Старая офлайн-сшивка не повторяется. Обычная точность прошла техническую пробу, но полная серия остановлена по стоимости после одного видео. Отдельная смешанная FP16 (пониженная числовая точность) проверяется по изменению признаков и собственной цене полного видео. Это не отрицательный итог качества MASA. Короткая проба сама по себе не означает научной HOTA.
