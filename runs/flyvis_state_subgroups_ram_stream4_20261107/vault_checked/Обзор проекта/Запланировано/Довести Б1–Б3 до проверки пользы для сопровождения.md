# Довести Б1–Б3 до проверки пользы для сопровождения

[[Обзор проекта/Запланировано|Запланировано]]

Б1 имеет первый обученный пилот на сохранённых запросах без подтверждённого преимущества. Б2 и Б3 прошли технические проверки обучаемости. Полная HOTA этих новых версий ещё не измерена. Следующее научное решение требует согласованного сравнения реального выхода трекера.
