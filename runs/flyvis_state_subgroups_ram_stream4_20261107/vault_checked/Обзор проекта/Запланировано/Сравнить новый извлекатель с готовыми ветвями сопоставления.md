# Сравнить новый извлекатель с готовыми ветвями сопоставления

[[Обзор проекта/Запланировано|Запланировано]]

**Критерий следующего полного сравнения.** Параметры выбираются только на данных разработки, после чего новая версия сравнивается с исходным трекером, прежним извлекателем и тремя бессмысленными контролями. Готовая сильная MASA остаётся отдельной справкой на общей первой двадцатке. Новая ветвь действует в текущих кадрах, старая MASA использует офлайн-сшивку. Её преимущество может зависеть от временного охвата и способа объединения обрывков, поэтому одно наличие признаков MASA не обещает такого же результата.
