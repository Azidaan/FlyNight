# Проверить источник малой прибавки от уточнения рамок

[[Обзор проекта/Запланировано|Запланировано]]

**Полная пиксельная проверка завершена.** Небольшая прибавка к исходному трекеру подтверждена во всех трёх сидах; устойчивый дополнительный вклад прошлого изображения не установлен. Результат записан в задаче выбора исправлений.

Текущая ограниченная проверка сравнит уже фиксированные пиксельные выходы с калибровкой по классам и числовым признакам без изображений. Параметры калибровки обучаются только на train, метод и сила выбираются только на dev, после чего сравнивается полная HOTA на тех же сорока val. Это последующая поисковая проверка, а не новый независимый итоговый тест. Большая прибавка не обещана; веса CNN и основной baseline не меняются.
