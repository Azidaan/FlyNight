# Доля положительных случаев с полезным выбранным ответом

↑ [[04 Термины и метрики/Термины и метрики|Термины и метрики]]

Для каждого видео: число выбранных полезных ответов, делённое на число всех положительных случаев; затем среднее по видео. Невыбранный случай не даёт полезного вмешательства. Отбор задаётся баллом без разметки.

- **Лучше:** higher
- **Единица:** доля
- **Диапазон:** [0, 1]
- **Чем считается:** scripts/z13_score_swap.py
- **Оговорка:** Диагностика выбора; отдельно считать выбранные отрицательные и неизвестные. Не точность среди отобранных, не HOTA и не оценка полного риска.
- **Источник:** runs/z13_score_swap_20261018/protocol.json
