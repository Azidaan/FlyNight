# Охват причинно доступных пар областей

↑ [[04 Термины и метрики/Термины и метрики|Термины и метрики]]

Доля исходных запросов, для которых есть поддержанные реальные области в текущем и строго предыдущем наблюдении. Не качество памяти модели.

- **Лучше:** higher
- **Единица:** fraction
- **Диапазон:** [0, 1]
- **Чем считается:** CPU-аудит сохранённых наблюдений
- **Оговорка:** Знаменатель и правило выбора прошлого обязательны; численные признаки FlyVis этим не проверяются.
