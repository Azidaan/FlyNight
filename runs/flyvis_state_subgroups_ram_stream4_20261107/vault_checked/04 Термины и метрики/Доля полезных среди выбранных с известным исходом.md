# Доля полезных среди выбранных с известным исходом

↑ [[04 Термины и метрики/Термины и метрики|Термины и метрики]]

В каждом видео выбираются ceil(0,05*N) строк из всех N по баллу считывателя без использования исхода. Доля полезных считается среди выбранных строк с известной разметкой; затем среднее по видео.

- **Лучше:** higher
- **Единица:** доля
- **Диапазон:** [0, 1]
- **Чем считается:** tracking/z13_competing_candidates.py:quota_precision
- **Оговорка:** Не HOTA и не гарантия отказа. Неизвестные исходы отдельно; изменение их доли может влиять на сравнение. Квота по каждому видео отличается от прежнего общего5%отбора.
- **Источник:** tracking/z13_competing_candidates.py:quota_precision
