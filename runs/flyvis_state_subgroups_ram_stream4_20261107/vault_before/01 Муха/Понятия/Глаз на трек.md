# Глаз на трек

↑ [[01 Муха/Муха (FlyVis)|Муха]]

На каждый трек сажается свой фовеальный глаз мухи (721 фасетка) — EyeBank. Глаз смотрит на окрестность рамки на всех кадрах 30 Гц, его внутреннее состояние «живёт» вместе с треком — по устройству это уже «один глаз — один трек», основа для [трекера на мухе↗](obsidian://open?vault=ObsidianFlyVis&file=01%20%D0%9C%D1%83%D1%85%D0%B0%2F%D0%9F%D0%BE%D0%BD%D1%8F%D1%82%D0%B8%D1%8F%2F%D0%A2%D1%80%D0%B5%D0%BA%D0%B5%D1%80%20%D0%BD%D0%B0%20%D0%BC%D1%83%D1%85%D0%B5).
