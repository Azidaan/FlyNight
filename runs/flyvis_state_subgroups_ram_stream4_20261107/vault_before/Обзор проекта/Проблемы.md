## 3. Как ведётся карта

Новый случай добавляется в историю существующей проблемы с первичным источником. Отдельный узел нужен для содержательной повторяемой проблемы, а не для каждого отказа запуска. Факт, рабочее объяснение, проверка и условие решения записываются отдельно.

Красный — открытая проблема, жёлтый — частично решённая, зелёный — решённая; фиолетовый — наблюдаемое повторение без установленной общей причины. Это статусы решения проблемы. У дерева гипотез цвет по-прежнему означает завершённость проверки.

Прежние P1–P11 сохранены без изменений и доступны из связанных записей. Они скрыты из обзора; файлы не удаляются и не переносятся. Реестр: [system_problems.json](file:///E:/Dissertation/experiments/system_problems.json).
