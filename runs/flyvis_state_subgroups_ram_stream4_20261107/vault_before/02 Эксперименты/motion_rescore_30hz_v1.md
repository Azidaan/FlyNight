# 🟢 Г0б-30: пересчёт слабых кандидатов на 30 Гц с признаком «движется иначе, чем фон» (DIS + гомография), без мухи

↑ [[02 Эксперименты/Направления/Уверенность детектора|Уверенность детектора]] · **Исход:** отрицательный · `motion_rescore_30hz_v1`

Следствие Г0б (temporal_rescore_5hz_v1): ложные кандидаты так же устойчивы во времени, как настоящие объекты. Проверяется отличие по движению: смещение рамки по цепочке сырых кадров 30 Гц минус смещение, предсказанное гомографией фона (DIS, RANSAC), согласованность остатка, изменение размера против масштаба гомографии, остаток DIS внутри рамки. Головы HistGradientBoosting: single (контроль), +tube (цепочка 30 Гц ±8 кадров), +tube+motion, причинная +tube+motion. Учатся на 130 видео train_cache «train» (только размеченные кадры вне обучающего списка детектора full_step5); оценка — dev+test 70 видео (те же правила кадров; детектор видел другие кадры этих видео) и val7 (не видел). Полнота при равном FP с исходной уверенностью на пороге 0,25 внутри набора; бутстреп по видео. Муха (T4/T5) — следующий гейт, только если этот пройдёт.

## Вопрос
Отличает ли «движение не как у фона» слабый настоящий объект от ложного кандидата настолько, чтобы вернуть часть потерь на пороге при том же FP?

## Гипотеза
Ложные кандидаты (знаки, отражения, фон) движутся по гомографии фона, настоящие участники движения — нет; признак движения добавляет к тубелету и даёт чистый возврат.

## Ожидалось (до прогона)
dev+test: голова tube+motion − база ≥ +3 % объектов ступени ПОРОГ при равном FP, ДИ > 0; tube+motion − tube > 0, ДИ > 0; на val7 знак тот же. Если выполнено — Г1: тот же пересчёт с признаками мухи вместо/поверх DIS. Иначе направление «пересчёт по времени» закрывается целиком.

## Что сделано
scripts/gate_motion_rescore_30hz.py: признаки по 207 видео (12 процессов, ~15 мин); головы на 907 897 кандидатах train (196 647 верных); оценка dev+test (70 видео, 112059 эталонов, ступень ПОРОГ 14497, бюджет FP 22238) и val7 (7 видео, 17572 эталонов, ПОРОГ 3114, бюджет FP 2367); бутстреп по видео 2000.

## Получено
Чистый возврат (доля объектов ступени ПОРОГ) при равном FP. dev+test: single -2,48 % [-6,17; +0,58], tube -0,74 % [-4,77; +2,63], tube+motion -0,10 % [-3,80; +3,01], причинная -1,25 % [-5,15; +2,08]; tube+motion − tube +0,64 % [-0,05; +1,38]; tube − single +1,74 % [+0,11; +3,18]. val7: tube+motion +1,45 % [-2,59; +6,02], tube+motion − tube +0,32 % [-0,33; +0,74]. Полнота dev+test: база 0.7786, tube+motion 0.7785; возраст 0: 0.4983 → 0.5107.

## Интерпретация
Временная цепочка на 30 Гц несёт немного информации сверх одного кадра (tube − single +1,7 %, ДИ > 0), движение относительно фона — ещё меньше (+0,6 %, ДИ задевает ноль), но всё вместе лишь догоняет исходную уверенность YOLO26: чистый возврат ≈ 0. Исходный балл детектора уже содержит почти всё, что дают время и движение; слабые кандидаты, которые он отсекает, неотличимы от ложных и по времени, и по движению.

## Решение
Критерии 1–3 не выполнены (dev+test −0,10 % при планке +3 %; движение поверх тубелета ДИ задевает ноль; знак на val7 другой) → completed_negative. По заранее записанному правилу направление «пересчёт слабых кандидатов по времени» закрыто целиком; гейт Г1 (муха в этом пересчёте) не запускается.

## Нельзя заявлять
Что движение не несёт информации об объектах вообще: проверены сжатые признаки рамки и разреженный DIS (шаг 32 px) с гомографией фона; dev+test — видео, кадры которых детектор видел при обучении.

## Условия
- **baseline:** исходная уверенность YOLO26, порог 0,25
- **variant:** головы single / tube / tube+motion / tube+motion причинная
- **dataset:** runs/train_cache (детекции 30 Гц, dis_quarter), runs/video_rate (val7); разметка box_track_20
- **split:** головы — train 130; оценка — dev+test 70, val7
