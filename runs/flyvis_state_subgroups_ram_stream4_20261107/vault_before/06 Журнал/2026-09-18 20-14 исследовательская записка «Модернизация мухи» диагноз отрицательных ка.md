# 2026-09-18 20:14 — исследовательская записка «Модернизация мухи»: диагноз отрицательных карточек и направления М1–М5 (на согласование)

↑ [[06 Журнал/Дни/2026-09-18|2026-09-18]]

*Диагноз (`dissertation/Исследование_модернизация_мухи.md`, [разд. 1↗](obsidian://open?vault=ObsidianFlyVis&file=05%20%D0%9F%D0%BB%D0%B0%D0%BD%2F1.%20%D0%A2%D0%B5%D0%BC%D0%B0%2C%20%D1%81%D1%82%D0%B5%D0%BD%D0%B4%20%D0%B8%20%D1%81%D0%BE%D1%81%D1%82%D0%BE%D1%8F%D0%BD%D0%B8%D0%B5%20%D0%BD%D0%B0%2011.09.2026)).* Все семь проверок использовали FlyVis как оценщик потока — в функции, где DIS заведомо сильнее. Разбор кода и кэшей: (1) вход `gray/255` без адаптации, тогда как FlyVis обучена при контрасте `exp(N(0, 0,2))` и яркости ~0,45 — ночной кадр (13–30/255) вне распределения; стратификация `runs/motion_reliability/report.json` по средней яркости ролика (dev+test, порог 60/255): на 43 светлых муха без DIS +0,013 AP над геометрией, на 27 тёмных −0,003; на тёмном `b1d22449` DIS сам вредит (0,448 → 0,356). (2) Фовея: медиана обрезки 79 px → 2,5 px/колонка при измеряемой ошибке 3,7 px; декодированный |поток| медиана 0,42 px — недооценка. (3) Литература 2026: замороженная FlyVis резко отказывает за границей обученного апертурного масштаба. (4) У FlyVis 734 свободных параметра (`NumberOfParams(free=734, fixed=2959)`); правило 1.2 «дообучение всего коннектома не выполняется» сформулировано шире, чем нужно: обучение свободных параметров при фиксированной топологии/знаках/счёте синапсов — процедура Lappalainen 2024, биологическое ограничение сохраняется.

*Направления ([разд. 3↗](obsidian://open?vault=ObsidianFlyVis&file=05%20%D0%9F%D0%BB%D0%B0%D0%BD%2F3.%20%D0%92%D1%81%D0%B5%20%D0%B8%D0%B7%D0%BC%D0%B5%D1%80%D0%B5%D0%BD%D0%BD%D1%8B%D0%B5%20%D1%87%D0%B8%D1%81%D0%BB%D0%B0)).* М1 адаптивный фронт-энд (фоторецептор Нака–Раштон + нормализация контраста ламины) — ~1–1,5 ч GPU, цель: восстановить сигнал мухи на тёмных роликах; М2 обучение 734 свободных параметров + обучаемая голова по всем 65 типам под трекерный loss с контролями (замороженная, перемешанный коннектом, параметрически согласованная сеть) — ~3–6 ч GPU, заменяет Н7; М3 разрешение/масштаб глаза (контекст 1,2–1,5×, два глаза, `extent` 25–31 с теми же параметрами); М4 функции, где муха «родная»: эго-движение (HS/VS) для компенсации камеры, лоуминг (LPLC2) для изменения рамки/окклюзии, STMD-признак малых целей, рекуррентное состояние как сигнатура для ассоциации; М5 ансамбль 50 чекпойнтов и калибровка декодера.

*На согласование по 6.5 ([разд. 4↗](obsidian://open?vault=ObsidianFlyVis&file=05%20%D0%9F%D0%BB%D0%B0%D0%BD%2F4.%20%D0%A7%D1%82%D0%BE%20%D0%B7%D0%B0%D0%BA%D1%80%D1%8B%D1%82%D0%BE%2C%20%D0%B8%20%D0%BF%D0%BE%20%D0%BA%D0%B0%D0%BA%D0%BE%D0%BC%D1%83%20%D0%BE%D1%81%D0%BD%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D1%8E)).* Добавить Н9–Н12 в реестр 1.7, Н7 → М2; уточнить 1.2 (свободные параметры обучаемы, топология нет); очередь М1 → М3(а) → М5 → М2 → М4; ступень 2 кэшей с полем фовеи и активностью всех типов.
