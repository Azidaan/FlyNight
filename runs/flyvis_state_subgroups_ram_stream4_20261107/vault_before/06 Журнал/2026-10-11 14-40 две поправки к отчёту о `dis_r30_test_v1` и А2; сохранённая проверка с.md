# 2026-10-11 14:40 — две поправки к отчёту о `dis_r30_test_v1` и А2; сохранённая проверка счётчика; решение автора

*Ошибка 1.* В отчёте ночной срез test назван «выделенным после прогона». Неверно: ночь указана в карточке справочным срезом до расчёта (`924bf32`). Верно: заранее названное описательное сравнение, не основной критерий; +1,207 [+0,248; +2,705] — не подтверждённое улучшение и не повод менять стенд.

*Ошибка 2.* Утверждение «n_first = n_last = min(5, end − start) у всех 235 тыс. жизней» было проверено разовой командой без сохранённого результата; сохранённый scripts/newval_long_false_oracle.py проверял только 97 новых val. Теперь сохранено (runs/signature_overlap_reconcile/count_check.json): train — 196216 жизней, нарушений n_first / n_last 0 / 0, совпадающих средних 167876, из них при > 5 измерениях 0, жизней с ≤ 5 измерениями 167876; dev — 49652 жизней, нарушений n_first / n_last 0 / 0, совпадающих средних 42432, из них при > 5 измерениях 0, жизней с ≤ 5 измерениями 42432; test — 54104 жизней, нарушений n_first / n_last 0 / 0, совпадающих средних 46237, из них при > 5 измерениях 0, жизней с ≤ 5 измерениями 46237; val7 — 11029 жизней, нарушений n_first / n_last 0 / 0, совпадающих средних 9343, из них при > 5 измерениях 0, жизней с ≤ 5 измерениями 9343; newval — 127281 жизней, нарушений n_first / n_last 0 / 0, совпадающих средних 108500, из них при > 5 измерениях 0, жизней с ≤ 5 измерениями 108500. Всего 438282 жизней.

*Решение автора.* Проверки DIS на dev и test закончены; ночь — основание только для будущей независимой проверки. А2 — следующая исследовательская ставка на FlyVis (не быстрый прирост); GPU — только на одну рабочую реализацию с одинаковой временной головой без мухи и с мухой, правилом остановки и новыми видео для подтверждения.
