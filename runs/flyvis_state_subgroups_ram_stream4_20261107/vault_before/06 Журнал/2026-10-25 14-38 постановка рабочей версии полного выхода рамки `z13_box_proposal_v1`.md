# 2026-10-25 14:38 — постановка рабочей версии полного выхода рамки `z13_box_proposal_v1`

↑ [[06 Журнал/Дни/2026-10-25|2026-10-25]]

*Действие.* Change the internal learned target-model output from a peak center to an observed detection XYWH proposal, then use the unchanged tracker distance. The target-conditioned ridge map is learned from the same observed exemplar and reused frozen. No offline new core/readout training; a working output-decoder prototype.

*Механизм.* Read unchanged final-query C/D/R1 maps. Project every actual high same-class detection into original eye crop. Retain center-in-crop regions containing at least one observed hex column. Region logit is the existing centered/scaled map mean inside that rectangle, NULLlogit0. Choose argmax including NULL, with NULL winning ties. Chosen real detection yields target XYWH; interpolate original mean toward it using alpha. Center-only twin changes only XY; box twin changes XYWH. Same selection/support/map/calibration/other state for each twin. Standard get_dists and full assignment are unchanged.

*Контроли.* D/C/R1 x center/box plus identical geometry-only centered negative squared-distance field around original prediction. Dold is original D peak action with the saved presence tau, canonical center and score, never retuned. Alpha0 is exact no-action in every arm. Unsupported/NULL remains original state. All unknown rows retained. No true box, identity or future input enters the decoder.

*Критерии до расчёта.* Dbox-baseline mean>=2pp and every paired95%video lower>0: Dbox versus baseline, saved Dold, same Dcenter, Cbox,R1box,geometrybox; plus differential box effect D-C and D-R1. All required. Partial positive contrast preserved but cannot promote failed full criterion to HOTA. Fit20 only, independently for each of8arms, alpha from[0,.25,.5,1] maximizes mean-video(beneficial-harmful)/known. Alpha0 first wins ties. Freeze selected indices in choice.json before any evaluation26 replay. No quota/score threshold/size/seed grid. Report all fit and evaluate alpha results.

*Отличие от испытанного.* Prior region mean/max prototypes replaced costs with categorical probability penalties; they did not move complete XYWH while retaining standard IoU/confidence costs. Prior size regressor predicted sizes directly; this version transfers an actual observed region selected by the same target-response model, with an otherwise-identical center-only twin. New admission is full-box minus center oracle +2.5419pp [1.8492;3.2842] in parent recovery1/report.json, not a claim of learned gain. No failed loss/normalization/state change is combined.

*Возражение.* Selecting real detector boxes can merely duplicate existing detector geometry and drift to neighbors. Region means/normalized confidence already failed in other interfaces, so this deliberately minimal intervention may still fail. Map features may lack identity/box-quality evidence. Equal eye and geometry-only controls must isolate FlyVis; even positive train26 shadow results require separate frozen closed-loop protocol.
