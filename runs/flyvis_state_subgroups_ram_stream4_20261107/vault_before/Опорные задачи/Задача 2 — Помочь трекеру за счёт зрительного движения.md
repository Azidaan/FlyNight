# Задача 2 — Помочь трекеру за счёт зрительного движения

↑ [[Обзор проекта/Эксперименты|Эксперименты]]

**Итог проверенной попытки:** Испытанное движение FlyVis не дало полезной прибавки.

## Задача

Найти применение движения изображения, которое действительно помогает сопровождению объектов.

## Что попробовали

Проверили несколько схем поправки прогноза трекера и сравнили сигнал FlyVis с классическим оптическим потоком DIS (оценка движения по изменениям изображения).

## Чем закончилось

Для классического движения полезная схема нашлась. Испытанный сигнал FlyVis в той же схеме вредил. Это отрицательный результат конкретного источника движения и способа его применения.

## Что дальше

Возвращаться к этой задаче при обоснованной замене качества сигнала или способа применения. Отрицательная реализация не закрывает все возможные варианты движения.

## Граница вывода

Предварительные схемы подбирались на данных разработки; их результат нельзя переносить на любой набор видео.
