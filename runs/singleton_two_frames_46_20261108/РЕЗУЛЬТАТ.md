# Предупреждение на двух кадрах: первая проблема, те же 46 видео

Без запрета: 117 передач, 21 последующая отмена, 22 известные правильные / 3 чужие / 92 неизвестные связи. Запрет по рождению: 86 передач, 11 отмен, 20 / 0 / 66. Запрет по двум кадрам: 95 передач, 11 отмен, 21 / 0 / 74. Оба запрета устранили те же 10 отмен на тех же связях и не создали новых. Из этих десяти связей одна была правильной, две — чужими, семь — неизвестными. Строгий критерий не потерять ни одной известной правильной связи не пройден.

В fit20 число конфликтов (без / рождение / оба) 6 / 2 / 2, известных правильных 4 / 3 / 3. В evaluate26 конфликты 15 / 9 / 9, правильные 18 / 17 / 18. Из 9 дополнительных передач при двух кадрах вместо одного восемь неизвестных и одна известная правильная — 1825→1914. Правильная 739→743 остаётся запрещённой, хотя без запрета её передача была отменена уже на следующем кадре. Это не переводит её в категорию чужих. Сверены 31 вторичное предупреждение, 93 задачи назначения и отмены в потоке кадров. Разметка использована только при оценке. Метрики целых видео не пересчитывались.

Отдельная проверка наличия материалов: из 22 запрещённых по двум кадрам для 12 есть готовые сопоставимые оценки по FlyVis, изображению и обычному движению. Среди 12 только 739→743 размечена, остальные 11 неизвестны. Ни у одной из трёх известных чужих нет полного комплекта двух карт: для 1996→2051 есть прошлая, но нет текущей; для 405→417 и 860→867 отсутствуют обе в проверенных манифестах. Следовательно, по готовым оценкам нельзя проверить безопасное восстановление правильной связи. Перечень точных последовательностей и наличия карт приведён в map_availability.json. Новые карты не вычислялись. Для проверки зрительного признака нужна та же геометрия, та же возможность восстановить ID и контроль по изображению/движению с сопоставимой частотой вмешательства; эти 46 видео уже изучались.
