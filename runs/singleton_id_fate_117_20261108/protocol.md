# Судьба публичного номера после 117 передач

Только сохранённые выдачи, назначения и разметка 46 видео. Набор — все 117 фактических передач варианта H, независимо от последующей отмены. Сравнение B0 (штатные номера), H (передачи без запрета), V (запрет при рождении), B (запрет при предупреждении на обоих кадрах). Порогов не менять, трекер/детектор/FlyVis/метрики полного видео не запускать.

Для каждого события целевой объект устанавливается только по уже сохранённым согласованным опорным меткам старого фрагмента в пределах 12 кадров до последнего наблюдения. Если такой метки нет — личность до события неизвестна, даже если новый трек позднее размечен. Следующее наблюдение не использовать для угадывания прошлой личности. Сопоставление рамок с разметкой — прежнее: свой класс, Hungarian, IoU>=0,5. Несопоставленная рамка не считается чужой. Сохранять прежние опорные соответствия и сверять их.

Целевой номер в каждом варианте — публичный номер старого штатного трека на последнем подтверждённом разметкой наблюдении до события. Восстановить таблицу публичных номеров по готовым связям и отменам, без повторного решателя. Проверить, что целевой публичный номер в H на назначении совпадает с записанным корневым номером; несовпадение выделить отдельно, не исправлять по будущему.

На каждом следующем размеченном кадре, где целевой объект явно присутствует в GT, проверить: (а) matched под целевым публичным номером; (б) matched под другим номером; (в) нет надёжного соответствия, хотя объект размечен; отдельно — подтверждённая выдача целевого номера другому объекту и дубли рамок этого объекта. Основная диагностика сохранения — успех на двух ближайших таких наблюдениях, без использования t+3 как конца конфликта. Если нет двух будущих наблюдений — недостаточно будущей разметки. Если неизвестна исходная личность — исход неизвестен. Отсутствие сопоставления выделять отдельно от смены номера. Показать также первую следующую контрольную точку и долю сохранённых среди всех последующих размеченных наблюдений; это диагностика, не замена HOTA.

По каждому старому штатному номеру найти первое фактическое возвращение после назначения и первое одновременное появление с новым номером, записать точную рамку, класс, уверенность и индекс исходной детекции. На ближайших фактических аннотациях показать принадлежность вернувшегося трека. Для сравнения с предупреждающей детекцией: только прямое совпадение исходного индекса в том же кадре либо сохранённая штатная траектория, однозначно принадлежавшая предупреждению, подтверждает связь. Если у предупреждения не было публичного трека, одной близости последующих рамок недостаточно для установления продолжения. Такое происхождение оставлять неизвестным. Не связывать рамки через будущее подбором IoU.

Отдельная сверка по всем 117, исключение догадок для неизвестных, явные знаменатели по доступности разметки, парные улучшения и ухудшения относительно B0 на одинаковых событиях, совпадение всех 21 отмен с прежним журналом. События одного видео могут быть зависимы; статистическую значимость и причинный эффект по отдельным событиям не заявлять.
