# История положения и размеров рамок: разбор 93 сохранённых пар

Действительный результат: [сводка](recovery1/result.json), [все решения](recovery1/pairs.json), [отдельная сверка и отмены](recovery1/audit.json). Условия сравнения записаны в [протоколе](protocol.md). Файл pairs.json в корне неполон: первая попытка остановилась из-за двух одинаковых измерений с одним временем. Она не является результатом. В 24 парах встретился такой повтор, расхождений координат нет. В recovery1 он считается одним наблюдением, формулы и пороги не менялись.

Нынешнее правило: 6 правильных / 1 чужая / 23 неизвестных. Прогноз по истории: 13 / 0 / 36; из 17 возвращено 7, из 6 не потеряно ни одной, 609→799 отклонена. Из 19 дополнительно принятых неизвестных четыре связи позже отменены при конфликте ID; всего 5 отмен против прежних 2. Ни одна из семи возвращённых не была отменена таким механизмом.

Сравнение одной прошлой и одной текущей рамки без скорости: 13 / 0 / 43. Проверка двух новых рамок относительно неподвижной прошлой: 13 / 0 / 40. Поэтому установлено отличие от прежней стоимости, но не надёжная прибавка от прогноза. При одинаковой квоте 30 пар до назначения: прогноз 7 / 0 / 23; одна рамка 6 / 0 / 24. Это разведочная диагностика, не правило для эксплуатации. Результат относится к меткам фрагментов на обучающих видео; целевой чужой пример был известен до разбора. Настройки трекера не менялись.
