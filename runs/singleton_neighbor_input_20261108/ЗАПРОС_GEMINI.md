Нужен поиск первичных работ и критический выбор одного следующего метода для сохранения личности объекта. Исходный код проекта тебе непосредственно не предоставлен. Разделяй известную механику ниже, вывод из неё и гипотезу.

В системе YOLO26 выдаёт рамки. XYWHByteTrack даёт исходные траектории, номера и прогноз Калмана. Авторская система исследует сохранение прежнего ID после пропуска. Зрительный модуль FlyVis формирует карты активности. Штатная FlyVis сама по себе готовым трекером с ID не является. Здесь выполняется офлайновое сравнение сигналов, назначение ID по этим оценкам пока не проверялось.

Первая проблема — у потерянного трека остаётся единственная геометрически допустимая рамка, которая может принадлежать другой машине. В сохранённом экспорте давность пропуска не больше двух кадров, пересечение рамки с прогнозом IoU не ниже 0,2. Геометрический допуск уже пройден. Требуется оценить, есть ли зрительное свидетельство продолжения того же объекта и когда данных достаточно для отказа.

Данные диагностические. Чужая пара 390→448, видео 00268999-cb063914, кадр 578. Старая личность 00034635 подтверждена на кадрах 566 и 572, текущая рамка принадлежит 00034637 на кадре 578. Своя пара 3→273, видео 02fa8491-2a4967e3, кадр 73. Прежний трек сопоставлен с 00053307 на кадре 61, текущая рамка с тем же объектом на кадре 73. Шаблон снят на кадре 71 без разметки, поэтому точная личность шаблона на этом кадре остаётся ограничением. Всего два события из разных видео. Вырезки на сравниваемых концах истории имеют размер 261 и 64 пикселя соответственно.

Глаз содержит 721 пространственную ячейку. У каждой пары есть три фиксированные опорные ячейки Q. Их выбирали по геометрии до чтения сигналов. Прошлая точка должна лежать в прошлой рамке, а все её 19 проекций — в текущей рамке и внутри сетки. Q одинаков для всех представлений и сдвигов. Текущая карта интерполируется по треугольникам. Сравниваем прогноз Калмана и лучший из 19 сдвигов радиуса два по гексагональной решётке. Масштаб вырезки между опорным и текущим наблюдением одинаков. Кандидатная рамка служит ограничением области, растяжения по её размеру нет.

Оценка S — сумма произведений центрированных значений, делённая на произведение общих норм. Среднее вычитается отдельно у каждого канала по Q, затем все каналы объединяются в один вектор. Нулевой знаменатель даёт отказ. Порог по двум примерам не выбирался. Оценка S не откалибрована как вероятность правильного ID.

У FlyVis C восемь нормированных каналов T4a–d/T5a–d. После стандартизации значения могут быть отрицательными. В формулу сходства поступают эти карты активности; штатный декодер оптического потока в данной формуле не участвует. Простой вход — тот же подготовленный рецепторный сигнал на той же сетке. Его временные фильтры обновляются по пяти сохранённым наблюдениям, общий префикс состоит из четырёх. Постоянные EMA равны 1,5; 3,9032; 12,2976; 32 шага наблюдений. EMA — экспоненциальное скользящее среднее. Нормировки взяты из прежней обучающей выборки.

Соседи — шесть ближайших ячеек, один шаг решётки. Их среднее сохраняет масштаб соответствующего центрального канала. При сравнении Q прежний, но сами соседи могут лежать вне рамки. Согласованный контроль без соседей повторяет те же четыре центральных EMA. Поэтому исправление порядка относительно варианта EMA+h−EMA уже возникает при замене состава каналов, и приписывать его соседям нельзя. Добавление соседей отдельно снизило максимум своей пары примерно на 0,003889, чужой на 0,030347.
