# Пространственный фильтр с отрицательными участками прошлого кадра

Из 200 сохранённых fit20 запросов физическую поддержку имеют 176; условно известны 45 (32 своих, 13 чужих) на 17 видео. AUROC FlyVis: корреляция 0.574519, фильтр 0.569712. Лучший простой фильтр, средние с соседями: 0.605769. Фиксированный направленный гейт не пройден. Источник `runs/background_patch_gate_20261108/summary.json`.

Одна зафиксированная реализация фильтра с реальными отрицательными пространственными участками не улучшила различение своих и чужих относительно той же корреляции и уступила простым признакам. Причина ошибки полного трекера не доказана. Это не воспроизведение BACF и не опровержение фонового обучения вообще.

## 1. Метод и отличие от прошлых попыток

Фильтр получает вектор всей пространственной раскладки цели, отдельный коэффициент на каждую пару позиция/канал. Положительный образец — прошлый шаблон. До64 отрицательных целых участков взяты из того же прошлого глаза, без пересечения с наблюдавшейся рамкой и без циклического замыкания границ. Нормировка по каналам прежняя; регуляризатор единичный, отрицательная ошибка усредняется, параметры не подбирались. После обучения отклик нормирован на отклик прошлого шаблона.

В старом z13_target_model_probe_v1 один вес канала применялся независимо ко всем ячейкам. Старые производные добавляли локальные наклоны. Новый фильтр сохраняет всю раскладку позиций. При отсутствии отрицательных образцов он точно даёт прежнюю корреляцию. Четыре математических теста и независимое решение Вудбери проверяют эту реализацию.

## 2. Условное ранжирование известных пар

AUROC — доля сравнений «оценка своей выше чужой» с половиной веса для равенства. Это диагностика, не качество ID полного трекера.

| Представление | Прежняя корреляция | Пространственный фильтр |
| --- | --- | --- |
| FlyVis | 0.574519 | 0.569712 |
| center8 | 0.576923 | 0.574519 |
| neighbor8 | 0.598558 | 0.605769 |
| input8_temporal | 0.603365 | 0.603365 |

Парные интервалы получены пересэмплированием видео, 5000 повторов, seed42. Все значения в summary.json, comparisons.

Только условные известные пары fit20, не независимое сохранение ID. 154 неизвестных исхода оставлены неизвестными. Поддержка определяется геометрией; один известный свой запрос не поддержан. Три известных поддержанных случая не имеют допустимых фоновых участков и сводятся к прежней корреляции. Полный трекер не изменён и не оценивался. DOI-resolver и Crossref API не открылись; содержание статьи проверено по первичному arXiv тексту, официальная MATLAB-ссылка вернула502, CVF PDF403.

## 3. Исполнение и решение

Все200 запросов сохранены, фильтр не получал метки личности. Они присоединены после расчёта. Восемь каналов каждого варианта, одинаковые опоры и19сдвигов. Карты и сеть не пересчитывались. 12 прямых строк сравнений взяты готовыми. Все новые результаты сохранены по запросам с защитой от повторного расчёта; интерполяция и независимая формула фильтра совпали до10⁻⁹.

Этот фиксированный фильтр не продвигать к независимому прогону трекера и не менять lambda по просмотренным меткам. Следующий узел активной цели — представление: проверить сохранность и восстановимость остальных26 из34 штатных выходных каналов, которые прежний экспорт C отбросил. Сравнение должно включать равные34 простых временных канала. Это проверка потери представления, а не анализ всех типов клеток ради полноты.

## 4. Литературное основание

Hamed Kiani Galoogahi, Ashton Fagg, Simon Lucey. Learning Background-Aware Correlation Filters for Visual Tracking. ICCV2017. Первичный текст https://arxiv.org/pdf/1703.04590, разделы3–4, уравнение3, рисунок2. Использован принцип реальных отрицательных участков; опубликованные FFT/ADMM, HOG, обновление и результаты авторов не воспроизводились.

Процент прироста качества трекера и доля потолка не определены: гейт не пройден и трекер не запускался.
