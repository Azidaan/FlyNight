# Считыватели сохранённых T4/T5 при неизменном ядре

Выбранный только на наборе подбора считыватель — Обычная небольшая сеть. Критерий перехода к полному трекеру не пройден.

Обучение — 667 пар из отдельной группы fit84; подбор — 90 пар fit20; оценка — 178 пар, 23 видео с парами из 26 исходных кластеров. Это прежние исследовательские видео. Вход каждого кандидата — восемь вкладов активности T4/T5, умноженной на прошлые коэффициенты образца цели. Все варианты получают ровно эти числа; геометрия и разметка не входят в предсказатель.

Ядро FlyVis, детектор, кэши и пространственное усреднение не менялись. Нового запуска ядра, видео или GPU не было. Нынешний балл равен сумме вкладов; обучаемые остаточные добавки первоначально равны нулю. У вариантов 9/21/37/19 параметров (linear/mlp/products/sigma_pi); 3 seed и 3 одинаковых уровня регуляризации, по 600 обновлений. Это сравнимые малые варианты, но число параметров не строго одинаково.

Независимый оценщик NumPy повторил все предсказания и выборы; максимальное отличие балла 1.77635684e-15 при заранее записанном допуске1e-9. Старый поднабор172 пар воспроизвёл104 верных. Метки независимо сверены с прежними исходными строками. Выбор модели и регуляризации восстановлен по dev, файл selection.json был сохранён до первого чтения оценочных входов исполнителем обучения. Источник: independent_audit.json.

Это диагностическая точность среди пар с известным верным кандидатом. Она не измеряет пропуски, неизвестные объекты, изменение последующих состояний и полные траектории. Новая голова не восстанавливает потерянную пространственным усреднением информацию. Нельзя по этому результату заявлять улучшение HOTA или отдельный вклад ядра относительно входа глаза.

Относительно прежнего считывателя доля верных у заранее выбранного варианта изменилась на -14,019%; измеренного потолка нет.

Решение: Полный трекер для этой версии не запускать. Не заменять победителя по результатам оценочного набора и не подбирать ещё варианты на этих примерах. Сохранить все неудачные сравнения; считать эту малую проверку законченной.
