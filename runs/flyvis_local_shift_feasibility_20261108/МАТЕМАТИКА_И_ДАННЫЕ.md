# Жизнеспособность локального поиска сдвига: проверка до протокола

## 1. Результат проверки

Геометрическое приведение к кадру и локальный поиск сдвига математически определены. Гарантии различения объектов из этого не следует. На имеющихся файлах можно выполнить ограниченную диагностику, но полноценное подтверждение безопасного восстановления одного кандидата сейчас не обеспечено составом размеченных пар. Новые проходы моделей, старые оценки качества и детекции не запускались.

## 2. Общие координаты

Пусть p — центр ячейки в координатах глаза, L=391, a — левый верхний угол вырезки, S=diag((x2-x1)/L,(y2-y1)/L). В сохранённой исторической системе координат:

$$x=a+Sp.$$

Для переноса объекта на d пикселей исходного кадра соответствующая позиция в текущем глазе:

$$p_t=S_t^{-1}(a_0+S_0p_0+d-a_t).$$

Это аффинное преобразование. Чистым сдвигом в глазных координатах оно становится только при S0=St. Изменение размеров детекции не следует использовать для выбора S: S определяется фактической входной вырезкой, а не кандидатом. Для нескольких кандидатов одного трека прогноз d0 должен быть одним и тем же.

Исторический frame_points использует формулу выше. При точном учёте центров пикселей cv2.resize возможна поправка x=a+S(p+1/2)-1/2. Разность между двумя соглашениями в межкадровом переносе равна (St−S0)/2; при равном масштабе она сокращается. Это надо оговорить для разных масштабов, а не объявлять прежние входы ошибочными.

Обратное преобразование численно проверено: ошибка 7,11e−15 пикселя. Интерполяция линейного поля в общей системе: ошибка 3,55e−15. Это проверка геометрии, не нейронной модели.

## 3. Почему приведение координат не выравнивает сами сигналы

Изменение масштаба входа меняет физический размер области усреднения рецептора, пространственных связей и временную историю. Приведение выходных координат не обращает эту фильтрацию. Для косинусоиды частоты k среднее по окну w меняет амплитуду в sinc(kw/2). При k=0,18 и w=8/16 получены коэффициенты 0,916/0,689: один перенос координат не делает их одинаковыми. Для рекуррентной нелинейной модели эквивалентность ещё менее очевидна.

Поэтому первичная математически чистая диагностика ограничена одинаковым размером вырезки между последним наблюдением и всеми последующими сохранёнными входами. Текущая последовательность должна продолжать ту же опорную последовательность. Эти условия проверены по метаданным. Ранее входы в опорном префиксе могут меняться, но у сравниваемой пары этот префикс общий. Геометрическая коррекция не гарантирует, что остаточная нейронная динамика переносится как изображение: это именно проверяемая гипотеза.

## 4. Когда сдвиг вообще различим

Для поля F(x) сдвиг d малой величины меняет его примерно на J_F d. Матрица J_F^T J_F должна иметь ранг 2, чтобы обе компоненты малого сдвига были локально определимы в обычной квадратичной ошибке. Для центрированной нормализованной корреляции условие строже: нужно исключить также изменения, поглощаемые вычитанием среднего и нормализацией амплитуды. Поэтому одного количества ячеек недостаточно; повторяющийся рисунок может создавать несколько максимумов.

На фиксированной области из 547 точек линейный перепад даёт корреляцию 1 для всех 19 сдвигов. На синтетическом двумерном рисунке найден заданный сдвиг (13;6,5): корреляция 0,999999 против 0,925282 без сдвига; отрыв от следующей гипотезы 0,037214. Это доказывает возможность работы формулы при различимом рисунке, но не наличие такого рисунка в T4/T5 машин.

Множитель из Gemini некорректен как универсальный штраф: отрицательная корреляция −1 после умножения на 0,01 становится −0,01 и обгоняет −0,5 при хорошем совпадении движения. Для первой проверки штраф движения исключается; область поиска одна и та же для всех сигналов. Если штраф понадобится позже, он должен задаваться отдельным аддитивным членом с заранее выбранным весом.

## 5. Что сохранено

Проверены по манифестам 399 файлов bbox_fit_maps и 152 bbox_normalized_signals; между ними есть совпадающие последовательности. Всего 507 уникальных ключей готовых признаков и 254 уникальные пары (200 fit20, 54 evaluate26).

В каждом проверенном готовом файле: C(721,8) — нормированные T4a–d/T5a–d; IMAGE(721,3) — рецепторная яркость и две пространственные производные в пиксельных координатах кадра; DIS(721,2) и DIS_VALID — обычное движение и его область определения; R1(721,34) — контроль рецепторных признаков, не нейронная активность Mi1. Все массивы конечны; полностью плоских карт C и яркости на всём глазе не найдено. Это не проверка информативности участка внутри рамки.

В более старом архиве C сохранён full(46,721,68) в проверенном первом блоке fit20. Происхождение и порядок этих признаков надо использовать по исходному коду: это не означает 68 типов клеток или полный рекуррентный state. Перечень 34 выходных типов включает Tm1, но не Mi1; нынешний экспорт пар выделяет T4/T5 с индексами 4:12. Для сравнения Mi1−Tm1 готовность данных не установлена.

Рецепторные входы сохранялись отдельно с frames/crops/hex. Признаки конкретных последовательностей сохраняют конечный срез, не все состояния по каждому промежуточному кадру. Наличие retinal-входов не означает наличие всех промежуточных нейронных карт. Новый DoG по исходному полноразмерному изображению в этих файлах отсутствует; IMAGE — уже отфильтрованное представление на той же сетке.

Медианы ячеек в прошлой рамке: 113 в fit-картах и 83 в normalized-картах; минимумы по 23. Для текущей рамки медианы 98 и 78,5, минимумы по 18. Эти наборы отличаются от всех 178 бинарных пар и всех 117 событий: обобщать число ячеек на них нельзя.

## 6. Общая область сравнения и фактическая доступность

Для каждого прошлого центра x_i заранее определить, что все точки x_i+d0+delta при всех 19 сдвигах находятся внутри текущей рамки и выпуклой оболочки текущей сетки. Прошлый x_i должен лежать в прошлой рамке. Область Q — пересечение этих условий для всех сдвигов, она фиксируется до чтения активности и меток. При интерполяции не выходить за выпуклую оболочку. Для всех сигналов, включая отсутствие поиска, использовать тот же Q.

19 сдвигов определены номинальным осевым базисом решётки (13;6,5) и (0;13) с радиусом 2; перевод в пиксели по масштабу вырезки. Полуцелый шаг учитывает идеальную решётку; реальные центры в архиве округлены, поэтому нужна интерполяция. Это фиксированный инженерный радиус, не оптимальный или выведенный из физиологии.

После одинакового масштаба, общего префикса и минимум трёх опорных точек в Q остаётся 142 пары: 107 fit20 и 35 evaluate26. Три точки — лишь минимальная алгебраическая поддержка, не научно достаточная информативность. После ограничения давности <=2: 62 пары, из них fit20 — 27 (2 правильные, 1 чужая, 24 неизвестные), evaluate26 — 35 (8 правильных, 0 чужих, 27 неизвестных). При давности до6 fit20 содержит 20 правильных,4чужих,83неизвестных; это другая область задачи, не замена условия <=2.

На 26 оценочных видео нет подтверждённых чужих в чистой готовой области. Следовательно, полноценный критерий безопасного выбора при одном кандидате на этих материалах проверить нельзя. Не увеличивать давность и не менять поддержку ради появления нужного результата.

## 7. Определённое математическое сравнение, ещё не запуск оценки

На одинаковом Q и тех же 19 гипотезах сравнивать три сохранённых представления: C(8каналов), яркость IMAGE[:,0], градиенты IMAGE[:,1:3]. Для каждого — прогнозный сдвиг d0 без поиска и максимум по 19 сдвигам. Это шесть оценок. Дополнительно пространственно переставленная C с тем же поиском — контроль случайного улучшения максимума.

Для каждого канала вычесть среднее по Q отдельно в прошлом и при данном текущем сдвиге; затем взять нормированное скалярное произведение всех элементов карты. Постоянные множители каналов должны оставаться прежними, без обучения на оценочных случаях. IMAGE и C уже имеют разные исходные нормировки; использовать сохранённую нормировку для C, а яркость и пару градиентов оценивать раздельно. Нулевой знаменатель — отказ, не нулевая оценка. Не использовать DIS_VALID как обязательную маску: иначе доступность обычного потока определяет доступность обоих методов. DIS не нужен в первичном score.

Основные разности: эффект поиска C_local−C_fixed, эффект поиска IMAGE_local−IMAGE_fixed, добавка C_local к лучшему заранее выбранному изображению. Сравнение лишь двух максимумов не отделяет источник сигнала от пользы геометрии. Ширину и высоту рамки кандидата не использовать как преобразование пространства карты. Не менять область Q при выборе выгодного сдвига.

Пары с отказом не исключать из отчёта молча. Не принимать решение о рабочем пороге по 35 оценочным случаям. Разметка нужна для определения правильности, геометрия — для доступности. Предварительное сравнение на этих данных может установить вычислимость и диагностический эффект поиска, но не безопасность полного трекера. Полный приёмочный протокол до восстановления достаточного набора своих и чужих не готов.

Первичные материалы: inventory.json, eligible_pairs.json, label_availability.json, mathematical_checks.json, identifiability.json, older_archive_header.json. Две технические неудачи сохранены: конфликт имени inspect со стандартным модулем (02cca71983eb49b19d3a29e21b5d0f1b) и неверная ось булевой маски (2c40baf7a61d47db9bddcdd8ae5f390e). Производная survey_recovery2 исправляет только маску; условия не менялись. Все готовые научные оценки и модели сохранены.
