# 7.1. Рельс В. Взвешивание обучения детектора по временной роли объекта

↑ [[05 План/7. Действующий план|7. Действующий план]]

**Главная и единственная линия с собственным методом.** Полностью расписана в
`09092026.md`, часть 3. Состояние на 11.09:

| этап | состояние |
|---|---|
| 1. Порядок в репозитории | почти закрыт; висят Д2а (снято здесь), Д4 (точка отсчёта), тексты |
| 2. Гейт исполнимости | **пройден**, признак доезжает побитово |
| 3. Признак на 1400 train-видео | **пройден**, 554 393 объекта |
| 4. Реализация взвешивания | **пройден**, проверен в обе стороны |
| 5. Подбор веса, 12 эпох | **идёт** |
| 6. Сквозная оценка и объявление новизны | ждёт |

**Критерий успеха записан до прогона:** рост доли найденных на возрасте 0 без
роста на возрасте 10+. Рост везде означает перекос рабочей точки, а не метод.

**Обязательная точка сравнения:** снижение `new_track_thresh` при равной
точности рождений (87.64%), а не при равном пороге. Иначе прирост метода
окажется приростом от сдвига рабочей точки.
