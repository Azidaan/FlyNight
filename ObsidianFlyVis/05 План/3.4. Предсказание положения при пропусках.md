# 3.4. Предсказание положения при пропусках

↑ [[05 План/3. Все измеренные числа|3. Все измеренные числа]]

Шкала гейта А (50 видео, подмена предсказания разметкой; «центр» — подменяется
только положение, размер рамки остаётся за Калманом):

| режим | IDF1 | к baseline | % к baseline |
|---|---|---|---|
| baseline | 51.014 | — | — |
| ошибка предсказания −2% | 51.11 | +0.09 | +0.18% |
| −5% | 51.24 | +0.23 | +0.45% |
| −10% | 51.85 | +0.84 | +1.6% |
| −25% | 53.47 | +2.46 | +4.8% |
| −50% | 57.12 | +6.11 | +12.0% |
| центр точен полностью | 57.48 | **+6.47** | **+12.7%** |
| вся рамка точна | 59.02 | +8.01 | +15.7% |

Читать так: отдача резко нелинейна, первые проценты не дают ничего, полезное
начинается с четверти. Разница между двумя последними строками (1.54 пункта) —
это размер рамки, то есть детектор, а не модель движения.
