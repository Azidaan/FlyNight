# 🔧 Конвейер оценки на исходном видео около 30 Гц

↑ [[02 Эксперименты/Направления/Исходное видео около 30 Гц|Исходное видео около 30 Гц]] · **Исход:** инфраструктура · `video30_pipeline`

Выравнивание исходных видео с редкой разметкой BDD100K, кэш детекций каждого исходного кадра, кэши движения и TrackEval после прореживания только выходов. GT внутри трекера не используется.

## Ожидалось (до прогона)
Трекер обновляет состояние на каждом исходном кадре; оценка — только на размеченных опорных кадрах; воспроизводимость при сброшенном счётчике траекторий.

## Что сделано
tracking/video_alignment.py, scripts/run_bdd_video_rate_experiment.py, кэши для семи доступных видео (7857 исходных кадров, 1318 размеченных).

## Получено
Стенд для семи видео (четыре обычных + три стресс-видео: пересвет, крайне тёмное, сложный фон). Ограничение на исходные видео 30 Гц из плана 11.09 снято 13.09.

## Решение
Стенд принят; этап 0 дорожной карты выполнен частично — не хватает исходных обучающих видео и окончательного разбиения.

## Ограничения
Семь видео; исходных обучающих видео нет (проблема P-DATA дорожной карты).

## Условия
- **dataset:** BDD100K, исходные видео
- **split:** 7 видео val
- **detector:** YOLO26s seed42, 960, порог сохранения 0.01
