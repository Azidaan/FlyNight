# 🔵 К1 v2: дообучение ядра мухи (734 свободных параметра) и декодера на нормализованном входе по единому протоколу

↑ [[09 Запланировано/FlyVis — планы|FlyVis]] · **Исход:** идёт · `fly_finetune_k1_core_v1`

Разрешение автора 06.10 («И К1»). Отличия от пилота К1: вход lcn24 (fly_input_norm_v1); обучаются свободные параметры сети (nodes_bias, nodes_time_const, edges_syn_strength — 734 числа; знаки и числа синапсов закреплены) и декодер, с притяжением к решению Sintel; шаг по масштабу параметров; единый протокол обучения и оценки (fade-in, точка отсчёта после fade-in, цель DIS; на обучении разгон 20 кадров без градиента + 12 с градиентом). Контроль — обучение только декодера на том же входе. 20 видео train пилота, 2000 шагов на ветвь; оценка — 17 видео dev пилота (перенос рамки) и отклик на скорости 1–8 px/кадр на других кадрах dev (scripts/fly_k1_v2.py).

## Вопрос
Улучшает ли дообучение ядра мухи на нормализованном входе перенос рамки сверх штатной мухи + lcn24 и сверх обучения одного декодера?

## Гипотеза
Свободные параметры ядра, настроенные на Sintel, неоптимальны для видео BDD; их дообучение на нормализованном входе повышает точность движения.

## Ожидалось (до прогона)
Ночь, dev: ядро ниже штатной мухи + lcn24 (6,76 px в [fly_input_norm_v1↗](obsidian://open?vault=ObsidianFlyVis&file=01%20%D0%9C%D1%83%D1%85%D0%B0%2F%D0%AD%D0%BA%D1%81%D0%BF%D0%B5%D1%80%D0%B8%D0%BC%D0%B5%D0%BD%D1%82%D1%8B%2Ffly_input_norm_v1)) хотя бы на 10 % с ДИ разности < 0, и ниже ветви «только декодер» с ДИ < 0. Если улучшение к штатной < 5 % — дообучение ядра для движения не продолжается (контроли P6 — перемешанная сеть, RNN того же размера — не запускаются).

## Условия
- **baseline:** штатная муха + lcn24 при масштабе 3,0
- **variant:** ядро + декодер; контроль — только декодер
- **dataset:** BDD100K MOT train_cache (train 20 — обучение, dev 17 — оценка)

## Критерии приёмки (записаны до прогона)
- ⏳ ночь, dev: ядро ниже штатной + lcn24 на ≥ 10 %, ДИ < 0
- ⏳ ночь, dev: ядро ниже ветви «только декодер», ДИ < 0

## Доказательства
- опорное число штатной мухи + lcn24: `runs/fly_scale_probe/real.json` · 2x3s1_lcn24.summary_night
- декодер не узкое место — ограничение в ступенях сети: `runs/fly_stage_probe/stages.json` · lcn24
