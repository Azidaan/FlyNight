# 🔵 Поиск схемы трекера, в которой внешнее движение даёт прирост HOTA (стенд XYWHByteTrack, 30 и 5 Гц)

↑ [[09 Запланировано/FlyVis — планы|FlyVis]] · **Исход:** идёт · `motion_scheme_search_v1`

Решение автора 06.10: сначала найти схему, где движение помогает трекеру (иначе пользу К1 нечем подтвердить в HOTA). [fly_input_norm_hota_v1↗](obsidian://open?vault=ObsidianFlyVis&file=01%20%D0%9C%D1%83%D1%85%D0%B0%2F%D0%AD%D0%BA%D1%81%D0%BF%D0%B5%D1%80%D0%B8%D0%BC%D0%B5%D0%BD%D1%82%D1%8B%2Ffly_input_norm_hota_v1): в подмешивании старого ByteTrack (XYAH, 30 Гц) не помогает даже DIS; BoT-SORT с компенсацией камеры на val7 — +0,07 HOTA (runs/video_rate/combined/botsort_*). Гипотеза: на 30 Гц сдвиг между кадрами мал и движение не нужно; рычаг — в больших разрывах (5 Гц, потерянные треки). scripts/motion_scheme_search.py: стенд XYWHByteTrack, сдвиг центра прогноза смешивается с движением рамки из поля (вес = уверенность поля); схемы r30_all / r30_lost / r5_all / r5_lost (5 Гц — только размеченные кадры, движение накапливается по сырым кадрам). Поиск — dev 35 видео train_cache (DIS), проверка — val7; затем муха + lcn24 в лучшей схеме.

## Вопрос
Есть ли схема стендового трекера, в которой DIS значимо повышает HOTA?

## Гипотеза
На 5 Гц (большие сдвиги между кадрами) движение рамки из поля улучшает ассоциацию и HOTA растёт.

## Ожидалось (до прогона)
Схема найдена, если на dev DIS − без движения > 0 с ДИ > 0 (бутстрэп по видео); проверка на val7 — тот же знак. В найденной схеме сравниваются муха + lcn24, без движения и DIS. Если ни одна схема не проходит — трекерная польза движения (и К1 ради трекера) не подтверждается.

## Условия
- **baseline:** та же схема без движения (штатный Калман)
- **variant:** DIS / муха + lcn24
- **dataset:** BDD100K MOT train_cache dev (35) + val7

## Критерии приёмки (записаны до прогона)
- ⏳ dev: в одной из схем DIS − без движения > 0, ДИ > 0
- ⏳ val7: в той же схеме знак DIS − без движения положительный

## Доказательства
- в прежней схеме DIS не помогает: `runs/fly_gain_recheck/hota_lcn24.json` · diff.dis-none
- компенсация камеры на 30 Гц ≈ 0: `runs/video_rate/combined/botsort_sparseoptflow_no_reid.json` · metrics.HOTA
