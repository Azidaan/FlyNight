## Вопрос
Даёт ли фильтр жизней с мухой больше HOTA, чем тот же фильтр без мухи, при одинаковом бюджете потерь?

## Гипотеза
Лучшее ранжирование с мухой (+0,0148 AP) переходит в прирост HOTA на test.

## Ожидалось (до прогона)
Критерий: test — HOTA «с мухой − без мухи» по видео > 0, ДИ > 0; val7 — тот же знак; потери с мухой на test ≤ 1 % объектов с попаданиями. Справочно — каждый фильтр против без фильтра, доля потолка того же действия, ночь.

## Условия
- **baseline:** фильтр жизней без мухи (бустинг)
- **variant:** фильтр жизней с мухой (бустинг)
- **dataset:** BDD100K MOT: train 130 (обучение), dev 35 (порог), test 35 + val7 (проверка)

## Критерии приёмки (записаны до прогона)
- ⏳ test: HOTA с мухой − без мухи по видео > 0, ДИ > 0
- ⏳ val7: HOTA с мухой − без мухи > 0 (знак)
- ⏳ test: потери с мухой ≤ 1 % объектов с попаданиями
