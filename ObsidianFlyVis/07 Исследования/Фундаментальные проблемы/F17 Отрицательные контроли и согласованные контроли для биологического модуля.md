# F17 Отрицательные контроли и согласованные контроли для биологического модуля

↑ [[07 Исследования/Фундаментальные проблемы/Фундаментальные проблемы|Фундаментальные проблемы]]

> Шум, свёртка того же размера, случайные веса, перемешанный коннектом, тот же вход без модуля; как засчитывать прирост именно мухе; эффект параметров и регуляризации.

## Механизм
A gain measured after inserting a biological module B into a pipeline is the sum of many effects, only one of which is 'the biology': (1) extra capacity / extra parameters and FLOPs; (2) extra input information that the module merely passes through (its own input re-sampled at a new resolution or field of view); (3) generic computation of the same family (temporal low-pass / leaky integration, centre-surround normalisation, divisive gain control) that any small filter bank provides; (4) regularisation: a noisy or redundant branch acts like dropout / feature noise, and VOneNet's own ablations showed that V1 stochasticity alone accounts for less than half of VOneResNet50's robustness gain, with removal of any single component destroying robustness (Dapello et al., NeurIPS 2020) - noise is an active ingredient, not neutral; (5) a condition proxy: the module's activity encodes illumination or contrast, so a downstream head uses it as a 'night indicator' (see F16); (6) optimisation luck: seed, data order, and the interaction between seed and early training dynamics (Bouthillier et al., MLSys 2021: variance from data sampling, initialisation and hyper-parameters is large compared with typical claimed gains and must be randomised jointly); (7) and only then the specific structure (connectome topology, cell types, trained biophysical parameters). Each confound needs its own control. Two methodological traps are especially relevant here. Trap A - weak nulls for topology: Dhiman (arXiv 2604.04033, 2026), using the same flyvis scaffold, showed that the apparent advantage of the connectome over a naive random graph (loss 0.514 vs 0.698 after 5 steps) comes from initialisation: with a checkpoint initialised connectome versus a random graph the gap is large, with shared random initialisation it vanishes (delta loss -0.002) and against a degree-preserving rewired null it is 0.5155 +- 0.0067 vs 0.5172 +- 0.0061 over 5 rewired graphs x 3 seeds. A rewired network that keeps the trained parameters of the intact network compares 'parameters tuned to this wiring' with 'the same parameters on the wrong wiring' - it tests detuning, not topology. Trap B - information-matched baselines: a module that sees its own input at a new sampling (721 hexagonal facets around a box) can win over the backbone simply because the input re-sampling is informative; the fair baseline is 'the same input without the module'. A third, generic trap is the non-biological matched control: Su and Kempe (arXiv 2304.09403, 2023) replaced the biologically motivated VOneBlock with a parameter-free wavelet scattering network plus Gaussian noise and obtained substantially larger adversarial robustness, i.e. the benefit belonged to the operator family and the noise, not to V1 biology.

## Где видно у нас
The project already runs most controls and they repeatedly removed apparent gains. (1) Own-input control: fly as re-identification signature +0.14 AP over geometry (0.4380 -> 0.5820 test), but the eye input alone gives 0.6248, fly alone is worse than its input by -0.0521 [-0.0765; -0.0295] (test), and on top of the input the fly adds only +0.0060 [+0.0007; +0.0118] test, +0.0065 [-0.0029; +0.0151] val7 ([[fly_matched_controls_v1]], runs/fly_reid_controls/report.json) - about 96 % of the apparent 'fly' gain belongs to the input sampling. (2) Shuffled connectome: real minus rewired fly, fly-alone head +0.0437 [+0.0273; +0.0595] test, but on top of the input +0.0032 [-0.0028; +0.0100] (15 better / 20 worse videos), one permutation seed ([[fly_connectome_null_v1]], runs/fly_reid_null/compare.json). Code check (tracking/connectome_null.py): the null permutes _target_indices within (sign x target type) groups and explicitly keeps all neuron and edge parameters of the trained intact model ('Параметры нейронов и связей не меняются') with no retraining. This is exactly the checkpoint-initialised regime that Dhiman 2026 showed inflates topology effects, so the +0.044 AP 'topology' effect on the fly's own representation is more safely read as 'trained-for-this-wiring versus detuned', not as evidence that connectome topology carries object information. (3) Same-front-end control for a different estimator: retina-lamina helps the fly (+0.016 over geometry on dark videos) but not DIS (+0.0012 [-0.0021; +0.0047] dark) ([[dis_retina_control_v1]]) - a correctly built matched control that localises the effect to the fly+front-end pair. (4) Shuffled-feature controls on q_match/q_alive/q_birth/motion reliability: fly T4T5 indistinguishable from shuffled T4T5 (+0.0010 [-0.0042; +0.0061]), and in several heads the fly is worse than base (q_match T4T5 -0.0024 [-0.0039; -0.0015]). (5) Same-size convolution control: the trainable wavelet layer 25.75 % versus plain convolution 25.84 % - without the control the gain would have been credited to wavelets (plan, sections 2 and 6). (6) DRB: one branch weight = 0 in all 896 channels and the frequency mask converged to neutral in 4/4 runs (the optimiser itself switched the module off - a built-in negative control), seed spread 0.0144 mAP at 12 epochs, sign flip at 100 epochs, +17 % time - the 12-epoch gains were inside seed noise. (7) Seeds: Ultralytics seed during fine-tuning from the same weights changes nothing, so the effective randomness is only data order / augmentation, and seed-only replicates underestimate variance.

## Решения из литературы
1) Equal-budget comparisons expose 'architecture gains' that are tuning gains: Melis et al. 2018 found that a carefully tuned standard LSTM outperformed more recent architectures on Penn Treebank and WikiText-2 when hyper-parameter budgets were equalised; Lucic et al. 2018 found that most GAN variants reach statistically similar FID once each gets the same search budget and many seeds. Practice: give every arm (fly, control) the same hyper-parameter search and report the best-of-N for each. 2) Random-weight and untrained controls: Jarrett et al. 2009 and Saxe et al. 2011 showed that convolution-pooling architectures with random filters reach a large fraction of trained performance (e.g. Caltech-101, NORB), so 'the module works' must be compared with 'the same module with random weights' [uncertain: exact percentages not re-verified]. For a connectome model the analogous controls are: same graph with random (re-initialised) parameters; trained parameters on a rewired graph; and rewired graph re-trained from the same initialisation (Dhiman 2026: only the last one isolates topology; under it the flyvis advantage was within +-0.007 loss). 3) Degree-preserving rewiring with multiple samples (Maslov-Sneppen swaps; Dhiman used 250 000 accepted swaps per graph, 5 graphs x 3 seeds) and reporting the activity scale before training (connectome 0.5682 vs rewired 0.5774) to exclude trivial scale confounds. 4) Non-biological operator of the same family: wavelet scattering + noise beat VOneBlock (Su and Kempe 2023); in this project's own history, plain convolution matched a trainable wavelet layer. The fly analogue is a bank of leaky integrators and centre-surround filters on the same 721-facet hexagonal input, with matched time constants and output dimensionality. 5) Noise / regularisation controls: VOneNet stochasticity explains less than half the VOneResNet50 robustness, so a Gaussian-noise feature of the fly's dimension and a feature-shuffle (permute fly features across samples within video) are both required; the shuffle keeps the marginal distribution and kills sample-specific information. 6) Statistics: paired bootstrap over videos (the project's unit), stratified CIs and interquartile means over seeds (Agarwal et al. 2021), and joint randomisation of data order, augmentation and initialisation (Bouthillier et al. 2021) rather than seed alone.

## Что сделать с мухой
Concrete control ladder for every future fly experiment (heads on cached features or trained modules), all with the same head type, same regularisation strength chosen by the same inner CV, same feature count, paired bootstrap over videos: C0 base (geometry [+ DIS] [+ calibrated conf]); C1 base + own input of the eye (721 facets, same field of view, same retina-lamina front-end if the fly uses it); C2 base + generic temporal-spatial bank on the same input (leaky integrators with tau matched to FlyVis photoreceptor/lamina constants, centre-surround difference of Gaussians, divisive normalisation), output dimension equal to the fly readout; C3 base + random projection of the input to the fly readout dimension with the same nonlinearity; C4 base + noise features (Gaussian, same dimension and variance) and C4b feature-shuffle within video; C5 base + illumination scalars (crop/frame luminance statistics); C6 fly with random parameters on the true graph (untrained connectome); C7 trained fly on a degree- and sign-preserving rewired graph (current null) with at least 5 rewiring seeds; C8 rewired graph RE-TRAINED with the FlyVis recipe from the same initialisation as the intact model (Dhiman-strength null); T fly. Credit rules: 'information beyond input' = T+C1 versus C1 (current +0.006); 'biological computation beyond generic dynamics' = T+C1 versus C2+C1; 'topology' = T versus C8 (not C7); 'trained biophysics' = T versus C6. Where the fly is trained end-to-end (F18), the matched control is a parameter-matched network (same number of free parameters, ~734 plus readout, same sparsity pattern size) trained with the same loss, and the rewired-and-retrained connectome trained with the same loss. The retina-lamina effect must be re-checked with C2 and C5, because a front-end that normalises luminance can turn any downstream feature into a better night proxy.

## Тест до постройки
Using existing signature caches and event datasets, no new FlyVis rollouts except C6/C7 seeds: (1) Fit C2, C3, C4, C5 heads on the existing fly_reid pairs (train 78 385, dev 31 390, test 32 178, val7 10 443) and the q_match/q_alive/motion-reliability event sets; these features are computed from the cached 721-facet inputs on CPU. If C2+C1 already reaches T+C1 (difference inside CI), the fly's residual +0.006 is generic dynamics, and no fly-specific training will be credited to biology. (2) Repeat C7 with 4 more rewiring seeds (each ~3 h GPU per the null card; can be reduced by rolling out only the test+val7 videos) to get a seed distribution for the current +0.0437 / +0.0032 numbers. (3) Activity-scale check: mean |activity| and saturation fraction per cell type for intact vs rewired fly on the same clips; if the rewired network is saturated or silent in many types, its loss of +0.044 AP is a dynamic-range effect. (4) Representational similarity: linear CKA between fly readout and (a) raw 721 input, (b) C2 bank output; CKA close to 1 with C2 predicts that the fly adds nothing a filter bank would not. All four are hours of CPU plus at most ~12 h GPU for extra rewiring seeds.

## Потолок
The creditable fly effect is bounded by the measured residual over the own-input control: +0.0060 AP test (+0.0086 dev, +0.0065 val7) in re-identification, i.e. about 1 % relative to the input-only head (0.6248) and about 3 % of the gap from geometry to geometry+input. Topology-specific credit is bounded by the real-vs-rewired difference on top of the input: +0.0032 [-0.0028; +0.0100] test; with a retrained null (C8) the expected value is lower still (Dhiman: connectome vs degree-preserving 0.5155 vs 0.5172 loss, within one SD). At the tracker level the stitching ceiling is small: geometry-only stitching gives +0.79 HOTA, appearance and fly on top are not significant. So even a perfect attribution protocol will most likely show a fly-specific contribution on the order of 0-0.01 AP in heads and 0-0.1 HOTA in the tracker [uncertain: tracker-level ceiling extrapolated from head-level numbers].

## Где обязано помогать
The controls must be evaluated on the subsets where biology is claimed to help: dark videos (fly over input +0.0102 [+0.0032; +0.0175] dark versus +0.0054 bright), glare videos, occlusion re-identification after track loss (lost-track stratum, q_match AP 0.386 versus 0.944 for tracked), and age-0 objects. No-harm check on bright/day videos and on the tracked stratum: every control and the fly must not reduce AP/Brier there (q_match T4T5 was worse on every held-out video, -0.0024). A gain only on dark videos that disappears under C5 (illumination scalars) is a calibration/illumination proxy, not biology.

## Отрицательный контроль
Mandatory minimum before any claim: own input (C1), generic matched filter bank (C2), noise and feature-shuffle (C4/C4b), illumination scalars (C5), untrained connectome (C6), rewired-and-retrained connectome (C8) with >= 3 rewiring seeds; plus for trained modules a parameter- and FLOP-matched non-biological branch (same size convolution / MLP with the same number of free parameters) trained with the same recipe and seeds. The current rewired-with-trained-parameters null (C7) is kept but reported as a detuning control, not as a topology control.

## Вклад ветви
For modules inside a trained network (DRB-like or a fly branch in the detector): log per epoch the norm of the branch output relative to the main path, the gate/mix weight, the ratio of gradient norms ||dL/dθ_branch|| / ||dL/dθ_main||, and run cheap ablation at checkpoints (zero the branch at inference and measure val mAP); DRB's 'weight = 0 in 896 channels' and 'mask converged to neutral 4/4' would have been visible after the first epochs. For heads on cached features: permutation importance of the fly block and the L1/L2 coefficient mass per block across bootstrap resamples.

## Минимальный эффект и стоимость
Head-level (cached features, CPU): video-bootstrap CI half-width for paired delta AP is ~0.005-0.006 on test (e.g. +0.0060 [+0.0007; +0.0118]), so MDE at 80 % power is about 0.008-0.01 AP; the current fly residual (+0.006) and the topology residual (+0.0032) are below MDE - more videos (dev+test+val7 pooled, ~140 videos) reduce the half-width by about 1/sqrt(2) to ~0.004, still at the edge. Cost: hours of CPU. Extra rewiring seeds: ~3 h GPU each for all 147 videos ([[fly_connectome_null_v1]] run took ~2.5 h wall with 7 processes), 4 seeds ~12 h. Retrained null C8: one FlyVis training run with the published recipe [uncertain: Lappalainen et al. trained 50-model ensembles; per-model cost on an RTX 5070 not measured here, likely tens of GPU hours]; Dhiman's matched-step protocol (5-10 optimisation steps) is a cheap surrogate but only tests early-training efficiency. Detector-level modules: if 0.0144 mAP is the between-seed SD at 12 epochs, MDE for a two-arm comparison is about 2.8 x 0.0144 x sqrt(2/n) = 0.033 (n = 3), 0.025 (n = 5), 0.018 (n = 10) mAP; at 4.3 h per 12-epoch run, 5 seeds x 2 arms = 43 GPU-hours, 10 x 2 = 86 GPU-hours - with C2-type matched branch a third arm adds 50 %.

## Вердикт для проекта
Primary methodological issue - it does not cause the failures, it explains why the few positive numbers shrink to ~0. Every apparent fly gain so far has been mostly absorbed by a matched control: own input absorbs ~96 % of the re-identification gain, shuffled features match fly readouts in q_match, DIS on the same front-end shows the retina-lamina effect is fly-specific but small, and the only significant 'topology' effect (+0.044 AP fly alone) used a null that keeps trained parameters and therefore cannot isolate topology (Dhiman 2026). Priority: high and cheap - add C2 (generic filter bank on the same input), C5 (illumination scalars) and more rewiring seeds before any further fly training; plan a retrained-null C8 only if the fly passes C2. Also record in cannot_claim that the topology statement is currently a detuning result.
