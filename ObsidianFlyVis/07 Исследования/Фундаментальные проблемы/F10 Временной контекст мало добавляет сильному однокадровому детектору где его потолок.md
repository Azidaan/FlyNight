# F10 Временной контекст мало добавляет сильному однокадровому детектору: где его потолок

↑ [[07 Исследования/Фундаментальные проблемы/Фундаментальные проблемы|Фундаментальные проблемы]]

> YOLOV, MAMBA, StreamYOLO: прирост только на размытии и заслонении; как заранее оценить долю кадров, где одиночный кадр проигрывает.

## Механизм
Temporal aggregation can only help on frames where the current frame is worse than its neighbours as evidence for the same object: motion blur, defocus, rare pose, partial occlusion, or a transient dip in contrast. On every other frame the single-frame score is already the best available evidence, and averaging with neighbours adds correlated, not independent, information. (1) Gains in the literature are concentrated in these degraded frames. FGFA (Zhu et al., ICCV 2017) split ImageNet VID objects by motion IoU with +/-10 neighbouring frames: over a ~74 mAP single-frame R-FCN (ResNet-101) the gain was +2.3 (slow), +4.1 (medium), +4.9 (fast); YOLOV++-S over YOLOX-S: slow 76.8 -> 83.7, medium 66.8 -> 77.0, fast 50.0 -> 62.3 mAP. The occlusion-heavy OVIS: YOLOX-S 39.0 -> YOLOV++-S 42.9 AP. YOLOV's own qualitative cases are 'rare pose' and 'motion blur'. (2) The large headline numbers rest on a weak base and non-causal context. YOLOV (Shi et al., AAAI 2023) gains +7.2 to +7.8 AP50 (YOLOX-S 69.5 -> 77.3, L 76.1 -> 83.6, X 77.8 -> 85.0), but the bases are trained 7 epochs on 1/10 of VID frames + DET, and reference frames are sampled from the whole video (future included). With local consecutive frames only, YOLOV++-S gains +1.0 to +4.6 AP50 instead of +6.2 to +9.2. MAMBA (Sun et al., AAAI 2021): 76.7 single frame -> 83.7/84.6 mAP with ResNet-101 and whole-video memory. (3) On driving video the temporal module mostly buys latency compensation, not better per-frame detection. StreamYOLO (Yang et al., CVPR 2022): YOLOX-L 31.2 -> 36.1 sAP on Argoverse-HD (+4.9), and the gain comes from forecasting the next frame; fusing the previous frame at the input (-0.9 sAP) or backbone (-0.7) hurts, element-wise add hurts (-0.4); only FPN-level concatenation with a next-frame target helps (+3.0). On extremely small objects (XS-VID) StreamYOLO 33.4 AP vs single-frame YOLOv8-L 33.6 - no gain. (4) Why a strong single-frame detector leaves little: a well-trained detector on a large labelled set (here 1,400 videos at 5 Hz) has seen many degraded views and already scores them; the residual errors are 'hard object' errors that are hard in every frame (the same object stays dark, small, or occluded for many frames), so neighbouring frames carry the same deficit. Temporal redundancy is only useful when degradations are transient relative to the object's lifetime. ODD-VOD (2023) uses exactly this: a per-frame detection-difficulty score lets 8 VOD models skip aggregation on easy frames with +73.3% FPS on average and no accuracy loss, i.e. most frames do not need temporal context. (5) Box-level vs feature-level: re-scoring after NMS (Seq-NMS, REPP) can only reorder candidates by their own score history; if the detector's score is already a sufficient statistic of time and motion (as measured here), box-level aggregation returns ~0. Feature-level aggregation (YOLOV, MAMBA) can create new evidence only where neighbouring frames contain a better view.

## Где видно у нас
Temporal and motion re-scoring of weak candidates, after the detector, returned nothing. Gate G0b (temporal_rescore_5hz_v1, 107 videos): rule-based tubelet scores -12 to -47% net return of threshold-lost objects; the learned head at night +1.6% [-0.6; +3.9] at equal FP (plank 3%), by day -4.6%. Gate G0b-30 (motion_rescore_30hz_v1, 30 Hz): dev+test single -2.48% [-6.17; +0.58], tube -0.74%, tube+motion relative to background (DIS + homography) -0.10% [-3.80; +3.01]; tube - single +1.74% [+0.11; +3.18] (CI > 0), tube+motion - tube +0.64% [-0.05; +1.38]; recall dev+test 0.7786 -> 0.7785; age 0 0.4983 -> 0.5107. Interpretation: the 30 Hz chain carries a little information beyond one frame, but together it only catches up with YOLO26's own score - exactly the signature of a strong single-frame detector whose score is a near-sufficient statistic. Frame accumulation before the detector (fly_eye_frontend_v1, G3) hurts: night recall at equal FP raw 0.7552, tavg3 -1.97 pp [-2.79; -1.22], tavg5 -5.69 pp, photoreceptor -9.45 pp, photoreceptor integration -15.13 pp; blindness at night 0.1047 -> 0.1222 (tavg3) -> 0.2167; background-homography averaging smears exactly the moving objects. The tracker's own box-level temporal logic (buffers, deferred birth, stitching) moved HOTA 58.47 -> 59.27 but not DetA (58.21 -> 58.17); FN 15,763 vs IDSw 2,221. Loss ladder at 960: found 69.2% night / 74.9% day, threshold 21.0% / 15.5%, localisation 4.2% / 2.8%, blindness 4.5% / 4.5%. The threshold loss is driven by objects that are hard throughout (score-IoU Spearman 0.73 day and night; equal-IoU control removes only 40% [33; 51] of the night gap; the IoU-free confidence target changes nothing: night -0.15 pp, age 0 -0.51 pp). The age-0 deficit (found 31% vs 68% at age 10+, 66% of it via threshold) has by definition no past observations of the object for a causal temporal module. Night mAP50 gap is carried by rare classes (97% in rider, bus, motorcycle, bicycle; car 0.817/0.816), which are also rare in time. Conclusion from project data: the frames where a single frame loses and a neighbour wins are a small share, and the project has never measured that share directly - which is the missing pre-build diagnostic.

## Решения из литературы
A. Measure the ceiling before building (the main lesson of ODD-VOD and FGFA): stratify objects by motion IoU, blur and occlusion, and aggregate only where the stratum shows an excess loss. ODD-VOD: +73.3% FPS across 8 VOD models with unchanged mAP by skipping easy frames. B. Feature-level, candidate-level aggregation with a frozen base (YOLOV/YOLOV++): select the top-k candidates after the head, refine their class score by affinity-weighted attention over candidates from reference frames; only the head projections and the aggregation module are trained. Numbers vs base: +7.2 to +7.8 AP50 on VID (weak, short-trained base, global frames); local causal frames +1.0 to +4.6 AP50; OVIS occlusion +3.9 AP (YOLOX-S) and +3.9 AP (SwinT 49.3 -> 53.2). Extra time ~1-4 ms per frame at S size. C. Memory banks over the whole video (MAMBA, MEGA): 76.7 -> 83.7-84.6 mAP (R-101), offline - not applicable to an online tracker except as an upper-bound oracle. D. Previous-frame fusion at the FPN with a forecasting target (StreamYOLO, LongShortNet, DAMO-StreamNet): +4.9 / +5.9 / +6.6 sAP on Argoverse-HD over YOLOX-L 31.2, mostly latency compensation; input/backbone fusion is harmful (-0.9 / -0.7 sAP). E. Box-level post-processing (Seq-NMS, REPP): helps mainly fast objects on VID; on a strong score it is near zero, which the project has already shown (G0b, G0b-30). F. Put the temporal signal where the strong single-frame detector cannot have it: (i) objects whose current view is worse than a recent view (occlusion onset, a car leaving a headlight glare zone), (ii) birth from motion before appearance is confident - but age-0 objects have no own past; (iii) stop treating temporal context as a detector problem and keep it in the tracker (track-conditioned confidence, as in ByteTrack's low-score association and PermaTrack's ConvGRU memory, Track mAP 60.3 -> 62.4). No paper was found that shows a temporal module beating a fully trained modern single-frame detector on BDD100K night [uncertain: search not exhaustive].

## Что сделать с мухой
The fly should not be a generic temporal smoother: G3 showed that pixel-level accumulation before a frozen YOLO26 hurts (tavg3 -1.97 pp, photoreceptor -9.45 pp at night). Three placements follow from the ceiling logic. (1) Fly as the affinity key for causal candidate aggregation (YOLOV placement, frozen YOLO26 and frozen fly): for each weak candidate at frame t, find the same object among candidates of frames t-1..t-k by cosine similarity of the existing foveal fly signature (retina-lamina front-end, which removes the fly's night dip), and pull the score from the best past view. Train only a small aggregation head. Rationale: the fly signature is the one temporal feature in the project with a measured identity value (+0.14 AP over geometry; +0.006 [+0.001; +0.012] over its own 721-facet input, +0.010 at night; topology +0.044 AP vs shuffled). Restrict to the 'past better view' subset defined by the diagnostic below. (2) Fly as a short recurrent memory on the P3 (stride 8) feature map, injected through a zero-initialised 1x1 conv at the FPN level (the only fusion point that helped in StreamYOLO), with YOLO26 frozen for the first epochs and the 734 fly parameters either frozen or fine-tuned on BDD (candidate K1). The fly's time constants give a memory of a few frames [uncertain], so the target is short occlusion onsets and blur, not long gaps. (3) Fly in the tracker, not the detector: track-conditioned confidence (q_alive) using the fly state of an existing track to keep a sub-threshold detection alive - this is where FN 15,763 lives and where the detector cannot see the past. In all three, the base detector stays frozen (no input-distribution shift, which G3 identified), the fly is the only new component, and an equal-information control (IoU-only key, DIS-propagated key, shuffled fly) is trained identically.

## Тест до постройки
Past-better-view oracle on existing caches (runs/det_cache_ctl_960, conf >= 0.01, 200 val videos, GT track IDs; and the 30 Hz caches of G0b-30). For every GT object lost at the threshold step at frame t (night and day separately), look back k = 1, 3, 6 frames (5 Hz) or 3, 9, 18 frames (30 Hz) along the GT track and ask: (a) was the same object detected with conf >= operating threshold (0.25) and IoU >= 0.5 in any of those frames? (b) is the max past conf above the current conf by >= 0.1? The share of threshold losses with (a) is the absolute ceiling of any causal temporal method; the share with (a) and the tracker NOT already holding a live track is the ceiling for DetA (losses already covered by the tracker's buffer give no DetA). Then stratify all GT objects by (i) motion IoU with +/-2 labelled frames (FGFA protocol: slow > 0.9, medium 0.7-0.9, fast < 0.7), (ii) Laplacian-variance blur of the GT crop, (iii) BDD occluded/truncated flags, (iv) age 0 vs 1-9 vs 10+, and compute the excess threshold-loss rate of each stratum over the slow-sharp-unoccluded stratum times its object count: that is the number of objects that a single frame loses because of transient degradation. Decision rule written before running: build any temporal module (fly or not) only if the DetA-relevant oracle share is >= 15% of night threshold losses (i.e. >= ~3 pp of the 21.0%) AND fast + blurred + occluded strata together contribute >= 30% of the excess night threshold losses; otherwise close the temporal-detector direction and move the fly to the tracker. Second check, feature redundancy: on matched object pairs (t, t-k) fit a linear probe from YOLO26 P3 features at frame t to the binary 'detected at t' label, and test whether adding the P3 feature at t-k (or the fly state) raises AUC by >= 0.005 (paired video bootstrap). Takes 1-2 h CPU, no training.

## Потолок
Literature: under causal local context the ceiling is +1.0 to +4.6 AP50 over a weak YOLOX-S base on VID, about +12 mAP on fast objects, +3.9 AP under heavy occlusion; on driving video almost nothing of the offline detection gain is shown (StreamYOLO's +4.9 sAP is forecasting). Project, measured upper bound for box-level time: G0b-30 net return -0.10% [-3.80; +3.01] of threshold-lost objects - effectively 0% of the gap. Project, estimated upper bound for feature-level time: the night-day gap at the threshold step is 21.0 - 15.5 = 5.5 pp; if 15-30% of night threshold losses have a past better view not covered by the tracker [uncertain: to be measured by the oracle], a perfect causal aggregator recovers ~0.8-1.7 pp of night recall, i.e. 15-30% of the night-day gap; translated into DetA this is at most +0.2 to +0.6 [uncertain], against a seed spread of 0.0144 mAP. Age-0 objects (66% of their deficit is threshold) have 0% ceiling for causal temporal context by construction. Blindness 4.5% cannot be addressed by candidate-level aggregation (no candidate to aggregate).

## Где обязано помогать
Must help: night objects of age >= 1 lost at the threshold step that were confidently detected in the last 1-6 labelled frames (the oracle subset); within it the fast (motion IoU < 0.7), blurred and occluded strata. Expected no effect: age 0 (no past), blindness (no candidate). No-harm checks: day recall at equal FP (G3 showed day -2.06 pp for tavg3, so day must be reported), the slow-sharp-unoccluded stratum (must be within +/-0.3 pp), FP count at the operating threshold (currently 8,242 FP in the tracker run; double counting of temporal evidence by detector and tracker can raise FP), IDSw (the low-threshold experiment cost +169 identity switches), and the 70 held-out videos plus val7 (rule 6.13: only unseen videos).

## Отрицательный контроль
Negative controls: (1) shuffled-connectome fly with the same training; (2) time-shuffled reference frames (references taken from a different video segment with matched brightness) - any gain that survives is not temporal; (3) reference frames = the current frame duplicated k times (same compute, zero new information). Matched (equal-information) controls: (4) IoU-after-constant-velocity key (geometry only); (5) DIS-propagated box key with the same k; (6) YOLO26's own P3 feature at the matched box as the affinity key (non-biological feature of the same frames); (7) the 721-facet input of the fly eye without the connectome (receptor-only), since the project already showed the fly adds only +0.006 over its input. A gain is credited to the fly only if fly > max(4, 5, 6, 7) with paired CI excluding 0 and fly > shuffled by at least half of the fly-over-geometry gain.

## Вклад ветви
Log per epoch: L2 norm of the zero-initialised fusion conv weights and the ratio |grad fusion| / |grad head|; attention entropy over reference frames (uniform attention = unused); the fraction of candidates whose score changes by > 0.05; and a per-epoch ablation on a fixed 10-video dev set (references replaced by the duplicated current frame). A branch whose weight stays ~0 (as the DRB branch did in all 896 channels) is a failed experiment, not a negative result about the fly.

## Минимальный эффект и стоимость
Oracle diagnostic: CPU only, 1-2 h, no GPU. Training-free causal aggregation with the fly key (signatures already cached for val7 / dev+test): 2-4 h. Gate thresholds: at equal FP, the paired video bootstrap half-width for night recall differences is ~0.8 pp (G3: tavg3 -1.97 [-2.79; -1.22]) and for relative net return ~3 pp (G0b-30), so MDE at 80% power, alpha 0.05 is about 1.1 pp night recall or ~4% net return of threshold-lost objects. Trained aggregation head with frozen YOLO26s and frozen fly: one 2-epoch run ~0.7 h; MDE for night mAP50 with control SD 0.0031: 2.8 x 0.0031 x sqrt(2/n) = 0.0071 with n = 3 seeds per arm, 0.0055 with n = 5 (5 x 2 x 0.7 h = 7 h). Note rule 6.12: Ultralytics seed does not vary when fine-tuning from the same weights, so seeds must vary data order manually. Full 12-epoch neck fusion (StreamYOLO placement): 4.3 h per run, 3 seeds x 2 arms = 26 h, plus a 100-epoch confirmation (~35 h) because the DRB sign flipped between 12 and 100 epochs. Fly memory at P3 full frame: 1.2 ms per step at 1/16 density, 15.8 ms full density on RTX 5070 (measured), i.e. +4-50% inference time [uncertain].

## Вердикт для проекта
Primary explanation for the failure of all post-detector temporal ideas (G0b, G0b-30, the tracker's DetA 58.21 -> 58.17) and secondary for G3 (where the dominant cause was input distribution shift). The literature's temporal gains live in transient degradations (fast motion, blur, occlusion onset) on weak, short-trained bases with non-causal context; the project's losses are mostly persistent 'hard object' losses and births, which a causal temporal module cannot reach. Priority: high for the cheap oracle diagnostic (it decides whether the temporal detector direction is open at all); low for building any temporal detector module before the oracle shows >= 15% DetA-relevant recoverable threshold losses. For the fly, the recommended path is identity-keyed aggregation or track-conditioned confidence in the tracker, not temporal smoothing in front of or inside YOLO26.
