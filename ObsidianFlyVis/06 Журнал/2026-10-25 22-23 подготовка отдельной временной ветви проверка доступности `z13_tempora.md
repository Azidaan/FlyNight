# 2026-10-25 22:23 — подготовка отдельной временной ветви: проверка доступности `z13_temporal_observation_gate_v1`

↑ [[06 Журнал/Дни/2026-10-25|2026-10-25]]

*Действие.* Prepare a distinct temporal FlyVis readout input: real candidate regions in an earlier stored observation of the SAME episode plus unchanged current regions. This gate only chooses and binds inputs; no learner or feature extraction.

*Критерии до расчёта.* All37296 current UID/episode/frame/track/choice bindings reproduce exactly; every selected reference strictly earlier/same episode; no true identity selection. Candidate resource admission: supported pair count>14252 and paired-video95%lower of oracle-reserve increment over old eligible pairs>0; expanded oracle mean>=.02 and lower>0. Existing model efficacy criteria do not change. If failed do not train this construction.

*Наблюдаемый выбор.* For each unchanged query, scan stored episode frames strictly earlier than current in reverse chronological order; choose latest frame with supported same-class real high-score regions under unchanged regions() API. Initial four observed exemplar frames are eligible. Never read ep_identity/ground-truth when selecting. Never use future frames or another episode. Preserve current state/history/choices exactly.

*Ограничение.* Previous prediction center is not reconstructed. Crop midpoint is supplied solely to regions() geometry which is DISCARDED; support and region indices do not depend on prediction. No invented previous prediction enters a model. Observation pixels are already cached fr_hex; activity still needs a separate matched extraction and causal replay. Earlier region is not assumed to be the same true object. A previous visible same-class region is not identity evidence; stale/wrong track IDs and distractors may defeat learning. This is an availability/oracle gate on repeated train26, not predicted model performance/HOTA or proof of temporal causality.

*Бюджет.* Только чтение метаданных/геометрии CPU600с+20с, независимый контроллер, без обучения/видео/GPU. Пространственный модуль остаётся временно отложенным. KeepTrack,ICCV2021 https://openaccess.thecvf.com/content/ICCV2021/html/Mayer_Learning_Target_Candidate_Association_To_Keep_Track_of_What_Not_ICCV_2021_paper.html motivates learned cross-frame candidate identities; this metadata gate is not its implementation.
