# 2026-09-16 23:58 — цель 6, первая карточка: жёсткое вето рождений по `q_birth` — компромисс покрытия, не улучшение.

↑ [[06 Журнал/Журнал изменений|Журнал изменений]]

*Постановка (карточка [[birth_policy_qbirth_v1]], записана до кода).* Единственное изменение относительно стенда — правило рождения: среди кандидатов со score ≥ 0,25 трек создаётся только при `q_birth` ≥ τ (голова base + DIS из [[event_heads_v1]], обученная на четырёх обучающих видео, коэффициенты в `runs/birth_policy/head.json`). Оба прохода ассоциации не тронуты; при τ = 0 выходы побайтово совпадают со стендом (тест). τ выбирался только на обучающих видео: τ_F1 = 0,327 (максимум F1), τ_prec = 0,198 (точность рождений ≥ контроль + 0,05 при полноте 0,963). Режим «спасения» слабых детекций не входил — голова на таких рождениях не обучалась.

*Получено (`runs/birth_policy/report.json`, три отложенных видео).* Контроль: HOTA 52,675, DetA 58,204, AssA 48,310, IDF1 57,685, IDSw 310, FP 552, FN 2 584, Frag 380; ложных рождений 2 212, истинных 2 269. τ_F1: ложные рождения 2 212 → 1 086 (−51 %, ниже на каждом видео), FP 552 → 417, IDSw 310 → 274, Frag 380 → 352, AssA +0,552, IDF1 +0,160; цена — истинные рождения 2 269 → 1 775, FN 2 584 → 2 841, DetA −1,253, HOTA −0,301; объектов, найденных хотя бы раз, 289 → 272 из 339; задержка первого правильного выхода +0,07–0,57 опорного кадра. τ_prec: ложные рождения → 1 455, FP → 507, IDSw → 302, FN → 2 717, HOTA −0,236, IDF1 −0,093. На обучающих видео (in-sample) τ_F1 улучшает всё сразу: HOTA +0,285, IDF1 +0,607, IDSw −26, FP −93 — на отложенных это не переносится по покрытию.

*Решение.* Три из четырёх записанных критериев выполнены (ложные рождения, FP, IDSw — лучше на каждом видео), HOTA-критерий (не ниже −0,1) — нет при обеих точках; по правилу плана 3.8 это компромисс покрытия. Карточка `completed_negative`; жёсткое вето не встраивается. Следующая карточка цели 6 — отложенное подтверждение: рождение с низким `q_birth` переводится в предварительное состояние и публикуется после N подтверждений, а не запрещается; ожидается сохранение выигрыша по ложным рождениям при возврате покрытия.

*Проверено.* 4 теста политики рождения зелёные; строгий валидатор — OK. Коммит `4c4f2a0` (код), следующий — журнал.
