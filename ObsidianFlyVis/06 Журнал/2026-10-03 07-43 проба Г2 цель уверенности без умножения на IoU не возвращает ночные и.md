# 2026-10-03 07:43 — проба Г2: цель уверенности без умножения на IoU не возвращает ночные и новорождённые объекты; правка цели закрыта

↑ [[06 Журнал/Журнал изменений|Журнал изменений]]

*Карточка [[conf_target_probe_v1]] (completed_negative).* Полнота при равном FP, ctl / iou_free: ночь 0.6541 / 0.6526 (-0,15 пп [-0,32; +0,03]); ночь, возраст 0 0.3892 / 0.3841 (-0,51 пп [-1,06; +0,06]); день 0.7129 / 0.7125 (-0,04 пп [-0,23; +0,14]); все, возраст 0 -0,48 пп [-0,91; -0,05]. mAP50 (val step5, 640) 0.42859 / 0.42802 (-0.0006). Порог при равном FP: ctl 0.2518, iou_free 0.3345. Исходный YOLO26 для справки: ночь 0.6500, день 0.7117, возраст 0 ночью 0.3884. Цель без IoU поднимает баллы в целом (тот же бюджет FP достигается на пороге 0,33 вместо 0,25), но не улучшает порядок «настоящий объект / ложный кандидат»: ночная полнота и полнота на первом появлении при равном FP не растут, а скорее падают (возраст 0 по всем видео −0,48 пп, ДИ < 0). Значит, связь «неточная рамка ↔ низкий балл», найденная в Г0а, — в основном общая причина (трудный объект), а не след умножения цели на IoU. mAP почти не изменилась.

*Методическая находка.* В Ultralytics 8.4.84 сид при дообучении от одних весов ничего не меняет: порядок данных и аугментации задаются константой (`ultralytics/data/build.py:350`). Для разброса при дообучении сид надо прокидывать в генератор загрузчика вручную.
