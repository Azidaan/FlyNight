# доля найденных

*share of GT objects with a correct detection*

Процент эталонных объектов, для которых детектор выдал верную рамку (по лестнице потерь). Считается по корзинам: возраст, размер, окклюзия, условие.

- **Лучше:** higher
- **Единица:** %
- **Диапазон:** [0, 100]
- **Чем считается:** scripts/miss_ladder.py, birth_cost.py, occl_scan.py
