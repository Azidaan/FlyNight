# 1.4 FlyVis и память объекта

Когда обновлять память машины, если сосед уже попал в её рамку?

У рекуррентного ядра FlyVis состояние нейронов изменяется от кадра к кадру. Обучение во время работы потребовало бы также менять веса по сигналу ошибки. Для трекера предложена отдельная задача — научиться выбирать наблюдения, которые можно записать в историю конкретного номера.

У зацикленного трансформера один блок применяется несколько раз. В работе об общей памяти повторные проходы обращаются к записям первого прохода. Авторы изучали языковые модели. Для памяти конкретных объектов при сопровождении ближе метод MeMOTR.
