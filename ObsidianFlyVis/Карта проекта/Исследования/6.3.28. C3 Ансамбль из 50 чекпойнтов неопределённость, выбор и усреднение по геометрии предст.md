# 6.3.28. C3 Ансамбль из 50 чекпойнтов неопределённость, выбор и усреднение по геометрии представлений

FlyVis ships an ensemble of 50 connectome-constrained networks (flow/0000/000-049), not a single model. Each one is a different local optimum of the same optic-flow task on the same connectome. The members differ only in their free biophysical parameters: time constants, resting potentials and synapse-strength scales. So far the project has used only model 000. The direction has three cheap uses. (1) Replication: are the fly's re-ID effects a property of FlyVis or only of checkpoint 000? These are +0.14 AP over geometry, +0.044 AP for intact vs rewired connectome, and +0.006 AP over the fly's own 721-facet input. (2) Ensemble as uncertainty: disagreement between K models on the same fovea input can act as a per-track reliability signal (q_match-style), and averaging K signatures gives a standard deep-ensemble feature. (3) Selection or averaging by representational geometry: pick or average models by the CKA/RSA similarity of their responses (the cluster medoid) instead of by task error. FlyVis parameters are tied to named cell types, so there is no permutation symmetry. That makes direct parameter averaging within a response cluster possible.
