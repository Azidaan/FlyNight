# 6.3.29. C4 Дообучение 734 свободных параметров (ночная адаптация той же задачей)

Train only the 734 free parameters of FlyVis (per-cell-type resting potentials and time constants for 65 types, plus per-type-pair synaptic strength scales for 604 edge types; topology, signs and synapse counts stay fixed) together with the decoder, so that the fly produces on artificially darkened / overexposed / noisy versions of bright frames the same output it (or DIS) produces on the clean bright frames. This is a connectome-constrained version of the day-to-night teacher-student / degradation-consistency adaptation that is standard in computer vision (2PCNet NightAug, DARTH, LTrack degradation suppression, DCPT/SAM-DA for night UAV tracking): the task stays the same, only the operating regime of the network is adapted. The same machinery can instead optimise a tracking loss (contrastive identity of the fly signature), which is plan item M2 / H7.
