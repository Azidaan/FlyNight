# 2.17.2.1. Цель 6: вето рождений по q_birth в неизменённом XYWHByteTrack (парная точка по точности рождений)

Состояние: завершён с отрицательным результатом. Код: `birth_policy_qbirth_v1`.

Уменьшает ли вето по q_birth число ложных рождений и FP на отложенных видео без роста IDSw и потери HOTA/IDF1 при парной рабочей точке по точности рождений?

Голова на train: 4 236 рождений (1 916+), точность контроля 0,452; τ_F1 = 0,327, τ_prec = 0,198 (точность ≥ 0,502 при полноте 0,963 на train). Отложенные видео, контроль: HOTA 52.675, DetA 58.204, AssA 48.310, IDF1 57.685, IDSw 310, FP 552, FN 2584, Frag 380; ложных рождений 2212, истинных 2269. τ_F1: ложные рождения 2212 → 1086 (−51 %, ниже на каждом видео), истинные 2269 → 1775; FP 552 → 417, IDSw 310 → 274, Frag 380 → 352, AssA +0.552, IDF1 +0.160; цена: FN 2584 → 2841, DetA -1.253, HOTA -0.301; объектов, найденных хотя бы раз, 289 → 272 из 339; задержка первого правильного выхода +0,07–0,57 опорного кадра. τ_prec: ложные рождения → 1455, FP → 507, IDSw → 302, FN → 2717, HOTA -0.236, IDF1 -0.093. На обучающих видео (in-sample) τ_F1 улучшает всё: HOTA +0,285, IDF1 +0,607, IDSw −26, FP −93.

Вето по q_birth делает то, что обещает уровень событий: вдвое меньше ложных рождений, меньше FP, IDSw и фрагментаций, лучше AssA. Но голова с AP 0,70 отсекает и ~22 % истинных рождений, часть объектов не рождается вовсе (−17 из 339) — покрытие падает сильнее, чем растёт идентичность, и HOTA снижается на 0,24–0,30. По правилу плана 3.8 это компромисс покрытия, а не улучшение идентичности. Жёсткое вето — слишком грубый механизм для головы такой точности.

Отрицательный по HOTA-критерию (3 из 4 критериев выполнены). Жёсткое вето не встраивается. Следующая карточка цели 6 — отложенное подтверждение: рождение с низким q_birth не запрещается, а переводится в предварительное состояние с требованием N подтверждений (tentative) — истинные объекты рождаются с задержкой, одно-кадровые ложные не публикуются.

Спасение слабых истинных детекций (не проверяется); новизну политики рождения до сравнения с литературой.
