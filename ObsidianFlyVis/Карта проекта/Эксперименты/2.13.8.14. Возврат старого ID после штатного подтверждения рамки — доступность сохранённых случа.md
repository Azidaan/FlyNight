# 2.13.8.14. Возврат старого ID после штатного подтверждения рамки — доступность сохранённых случаев

Состояние: инфраструктура. Код: `singleton_native_confirm_inventory_v1_20261108`.

Есть ли в сохранённых fit20 состояниях новые подтверждённые фрагменты, которым можно причинно вернуть потерянную личность?

20 fit-видео, 23 529 кадров: полный исходный выход совпал с сохранёнными B0; обнаружены 88 моментов с 93 допустимыми рёбрами к впервые подтверждённому новому фрагменту. Архивные стоимости, первые пары, прогнозы и истории совпали (runs/singleton_native_confirm_20261108/native_trace_complete.json).

Подтверждена доступность причинной проверки, но правильность новых связей ещё не оценена.

Проверить качество возврата метки при неизменных штатных рамках; сначала геометрия без FlyVis.

Прежняя офлайн-сшивка уже существовала. Здесь проверяется доступность причинного решения без будущих кадров. Нулевая доступность в архиве запросов не означает её отсутствия между запросами. Проблемы 2–4 не исследуются.
