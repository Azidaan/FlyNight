# 2.13.4.17. З13: признаки мухи против входа глаза той же размерности (онлайн-модель цели)

Состояние: завершён с положительным результатом. Код: `z13_target_model_r1_v1`.

Сохраняется ли преимущество признаков FlyVis над входом глаза в онлайн-модели цели, если вход глаза представлен тем же числом временных каналов?

17.10, процессор, 1 мин 37 с. R1 (34 временных канала входа глаза, λ = 1.0 по 20 видео train104; runs/z13_target_model_r1_20261017/R1/choice.json): доля полезных центров среди 1786 положительных train26 — общая 0,081, по видео 0,087, медиана ошибки 0,772 доли масштаба; R0 0,092, C 0,152, D 0,175 по видео (строки C0 / C / D / R0 — из runs/z13_target_model_20261017). Парно по видео (runs/z13_target_model_r1_20261017/report.json, paired): D − R1 +8,83 п.п. [+5,43; +13,21], лучше 22/26; C − R1 +6,47 п.п. [+2,56; +11,08], лучше 20/26; C0 − R1 +7,06 п.п. [+2,82; +11,99], лучше 17/26; R1 − R0 -0,52 п.п. [-1,91; +0,75], лучше 8/26. По истории (by_history): кадры поиска ≤ 3 — D − R1 +10,33 п.п. [+6,52; +14,88], лучше 21/26, C − R1 +8,41 п.п. [+4,48; +13,07], лучше 19/26; > 3 — D − R1 +6,36 п.п. [+2,74; +9,99], лучше 18/25, C − R1 +3,19 п.п. [-1,06; +7,13], лучше 15/25.

Преимущество признаков FlyVis над входом глаза в онлайн-модели цели сохраняется при равной размерности: D +8,83 п.п., C +6,47 п.п., C0 +7,06 п.п. против R1, ДИ > 0; R1 не лучше R0 (−0,52 п.п.) — число временных каналов разрыв не объясняет. Разрыв больше на ранних кадрах поиска; на поздних у C интервал включает ноль. Остаётся необъяснённым, что именно даёт муха: R1 не имеет пространственной обработки шире 6 соседей, а муха объединяет сигнал многих колонок; более строгий контроль — пространственно-временной банк фильтров входа без коннектома.

Вывод «в признаках FlyVis есть сведения для узнавания цели сверх входа глаза» подтверждён на двух контролях входа (в рамках онлайн-модели цели, train26, поиск). Следующий содержательный контроль — пространственно-временной банк фильтров той же размерности (процессор, минуты); решение — за автором. Узел онлайн-модели по-прежнему не лучше прежнего считывателя (z13_target_model_probe_v1).

Нельзя заявлять роль коннектома или анатомии: C0 на том же графе не хуже C, контроля с перемешанным графом нет. Нельзя заявлять пользу для трекера или HOTA. train26 многократно использован; один набор настроек узла.
