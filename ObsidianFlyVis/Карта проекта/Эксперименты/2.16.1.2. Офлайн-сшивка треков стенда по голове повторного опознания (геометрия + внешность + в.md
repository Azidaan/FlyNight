# 2.16.1.2. Офлайн-сшивка треков стенда по голове повторного опознания (геометрия + внешность + вход глаза) — HOTA/IDF1/IDSw на обучающих видео

Состояние: завершён с положительным результатом. Код: `stitch_appearance_v1`.

Сколько дают стенду офлайн-связывание обрывков треков по простой внешности?

dev / test / val7: без сшивки HOTA 61.336 / 58.469 / 54.573, IDF1 69.264 / 66.965 / 60.380, IDSw 1990 / 2221 / 526; сшивка HOTA 61.963 / 59.301 / 55.205, IDF1 70.940 / 68.741 / 62.214, IDSw 1613 / 1792 / 420, связей 1053 / 1144 / 265. Бутстреп по видео: test ΔHOTA +0.841 [+0.266; +1.517], ΔIDF1 +1.758 [+0.695; +2.983], ΔIDSw на ролик -12.26 [-15.49; -9.40] (лучше в 35 из 35); val7 ΔHOTA +0.440 [+0.150; +0.809], ΔIDF1 +1.354 [+0.712; +2.029]. Абляция признаков (runs/fly_reid_ablation/report.json, тот же протокол): test HOTA / IDF1 / IDSw — только геометрия 59.283 / 68.791 / 1795; + картинка и цвет 59.347 / 68.844 / 1777; + вход глаза 59.301 / 68.741 / 1792. Геометрия − стенд: ΔHOTA +0.793 ДИ [+0.228; +1.440]; картинка и цвет − геометрия: +0.082 ДИ [-0.187; +0.329]; вход глаза − картинка и цвет: -0.035 ДИ [-0.171; +0.095].

Значимая часть переключений ID стенда — обрывы трека с новым рождением поблизости в течение 2 с; простая внешность (картинка, цвет, вход глаза) и геометрия связывают их надёжно: IDSw ниже на всех 35 роликах, HOTA и IDF1 растут и на test, и на val7. Абляция: почти весь прирост (+0,79 из +0,84 HOTA test) даёт одна геометрия; внешность (+0,08) и вход глаза (−0,04) незначимы. AP пар (геометрия 0,438 против 0,686 с внешностью) почти не предсказывает HOTA: жадная сшивка с низким порогом меняет считаные связи.

Сшивка по одной геометрии — самый дешёвый и почти полный вариант (не требует ни мухи, ни внешности); внешность оставить опцией. Порог 0,2 на краю сетки — проверить ниже; совместить с каскадом буферов.

Новизну метода: офлайн-связывание треков известно (AFLink, GSI).
