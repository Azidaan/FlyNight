# 2.13.5.24. Г3: глаз мухи перед детектором — замороженный YOLO26 на кадрах после фоторецептора и накопления (без обучения)

Состояние: завершён с отрицательным результатом. Код: `fly_eye_frontend_v1`.

Даёт ли накопление света и адаптация фоторецептора мухи детектору свидетельство, которого нет в одном кадре, — прежде всего ночью?

Полнота при равном FP, вариант − raw. dev+test ночь (raw 0.7552): tavg3 -1,97 пп [-2,79; -1,22], tavg5 -5,69 пп [-7,06; -4,44], pr -9,45 пп [-11,54; -7,68], pr_int -15,13 пп [-17,20; -13,15], pr_tavg3 -8,31 пп [-10,32; -6,64]. dev+test день: tavg3 -2,06 пп [-3,64; -1,07], pr -2,88 пп [-3,49; -2,30]. val7 все: tavg3 -1,54 пп [-2,38; -0,79], pr -3,21 пп [-5,44; -2,21]. Слепота ночью dev+test: raw 0.1047, tavg3 0.1222, pr 0.1585, pr_int 0.2167.

Замороженному YOLO26 любой обработанный вход вреден, и вред растёт со степенью изменения кадра; растёт и слепота (объект не находится даже при conf 0,01) — признак сдвига распределения входа, а не только шума. Накопление по гомографии фона размывает именно движущиеся объекты (они движутся не как фон) — чем больше кадров, тем хуже (tavg5 хуже tavg3); интеграция фоторецептора без компенсации (pr_int) — хуже всех. Ночью у BDD100K нет фотонного голода в смысле, который лечит накопление: H.264 уже сглаживает шум во времени.

Критерии 1–3 не выполнены (лучший вариант ночью tavg3 −1,97 пп; варианты мухи хуже лучшего tavg) → completed_negative для замороженного детектора. Заранее записанный следующий шаг — дообучение на лучшем варианте — не даёт мухе преимущества: лучший вариант небиологический (tavg3), а мушиные хуже его; решение о дообучении на pr (адаптация без временного размытия) — за автором.

Что вход мухи бесполезен для детектора вообще: детектор не дообучался на обработанных кадрах (сдвиг распределения), накопление компенсировалось только по фону, а не по объекту.
