# 2.13.4.9. Доля коротких жизней с совпадающими первым и последним средними мухи и их доля в запасе удаления (новые val-видео)

Состояние: завершён с положительным результатом. Код: `newval_signature_overlap_v1`.

Какая часть жизней и какая часть запаса удаления приходится на жизни, у которых сигнатура мухи не различает начало и конец?

runs/newval_signature_overlap/report.json. Доля жизней с совпадающими первым и последним средними мухи: все размеченные — 8260 из 26264 (31.4 %); полностью ложные — 3413 из 6342 (53.8 %); настоящие/смешанные — 4847 из 19922 (24.3 %); удалённые ложные (с мухой, 0,7) — 159 из 205 (77.6 %); ошибочно удалённые настоящие (с мухой, 0,7) — 154 из 202 (76.2 %); пропущенные ложные — 3254 из 6137 (53.0 %). Ложных рамок в таких ложных жизнях — 3433 из 10707 (32.1 %). Оракул только по полностью ложным жизням с совпадающими средними: ночь — без фильтра 57.678 → 58.072 (полный оракул 58.920), доля запаса 31.7 %; день — без фильтра 57.754 → 58.209 (полный оракул 59.418), доля запаса 27.3 %; все — без фильтра 57.714 → 58.129 (полный оракул 59.101), доля запаса 29.9 %.

У 54 % полностью ложных жизней (и у 77 % удаляемых головой с мухой) первое и последнее средние мухи численно совпадают (правило отбора: n_first = n_last и first_fly ≈ last_fly, допуск 1e-4); это не доказывает для каждой жизни, что окна построены из одних и тех же измерений. Различение в этой группе слабое, но не случайное: среди всех размеченных жизней с совпадающими средними ложных 41 % (3 413 из 8 260), среди удалённых головой — 51 % (159 из 313). Оракул, удаляющий только полностью ложные жизни с совпадающими средними, даёт 31,7 % прироста полного оракула ночью и 27,3 % днём; это отношение двух приростов HOTA — сказать, что остальные две трети принадлежат жизням с различающимися средними, нельзя (HOTA после удаления разных групп не складывается; нужен оракул по ним). Опыт показывает, сколько теряется при нынешнем представлении сигнала (усреднение), но не доказывает, что сохранение последовательности улучшит различение.

Число — для решения автора о проходе мухи по истории жизни (пока не рекомендован, но и не закрыт). Следующее по разрешению автора — диагностика контекста (а) соседние треки (life_context_neighbors_v1), затем отдельно (б) цепочка и внешность.

Описательная диагностика на уже прочитанных видео; польза временной истории мухи этим не доказана и не опровергнута; доля запаса — по оракулу с разметкой.
