# 2.13.4.3.3.1.1. Остаток запаса оракула O2 после сшивки MASA (проверка перед З13)

Состояние: завершён с положительным результатом. Код: `o2_masa_residual_v1`.

Сколько из запаса оракула O2 (fovea_target_30hz_v1: +0,47 HOTA без сшивки) остаётся после сшивки MASA стенда — то есть сколько может взять З13 (обученное объектное считывание мухи) поверх нынешнего лучшего выхода?

Окно 20:16–22:13 12.10 (≈ 2 ч; 25 мин простоя — зависание трёх процессов CUDA при запущенной игре, сторож перезапустил, сбоев 0). Сверка: O2 без сшивки из нового сборщика — 61,807 (эталон 61,807) — runs/o2_masa_residual/report.json, repro_o2_none. Dev 35, HOTA общий: стенд + MASA 61,655, O2 + MASA 61,988, стенд без сшивки 61,336, O2 без сшивки 61,807 — runs/o2_masa_residual/report.json, pooled. O2 + MASA − стенд + MASA: общий +0,333, по видео +0,377 [+0,076; +0,720], лучше 24/35; O2 − стенд без сшивки: общий +0,471, по видео +0,547 [+0,236; +0,900], лучше 27/35; MASA поверх O2: общий +0,181, по видео +0,175 [-0,065; +0,388], лучше 25/35 — runs/o2_masa_residual/report.json, diff. Ночь (15 видео): O2 + MASA − стенд + MASA общий +0,141, по видео +0,163 [-0,100; +0,424], лучше 10/15. Длинных разрывов (> 30 кадров) после MASA: стенд 401, O2 395; всех разрывов 2144 и 2066 — runs/o2_masa_residual/report.json, breaks. Поправок для пар, не проходивших порог до вмешательства (стоимость своей пары ≥ 0,8 до поправки; изменение фактического назначения не проверялось): 1721 (у потерянных треков 1177) — runs/o2_masa_residual/report.json, oracle_events.

После сшивки MASA сохраняется около 71 % исходного прироста общей HOTA от O2 (+0,333 из +0,471). Какие именно исправления оракула и MASA пересекаются, не установлено: разность итогов HOTA (≈ 0,14) не является числом общих исправленных случаев. Число длинных разрывов после MASA почти не меняется (401 → 395), всех — 2144 → 2066; это согласуется с гипотезой, что прирост связан с короткими разрывами, но не распределяет прирост HOTA по причинам — O2 действует и на ведомые треки (246 752 применения против 4 351 у потерянных). Ночью (15 видео) положительный эффект не подтверждён: +0,163 [−0,100; +0,424] — оценка недостаточно точна, близость к нулю тоже не доказана. Критерий допуска выполнен (общий +0,333 при пороге +0,3, ДИ по видео > 0); нижняя граница ДИ +0,076 — это не доказательство, что истинный прирост больше +0,3.

По заранее записанному критерию З13 допускается к одной ограниченной реализации; запуск — решение автора. +0,333 — ориентир запаса для проверенного сценария оракула (своя уверенная детекция в области глаза), а не строгий потолок всей З13: иное правило вмешательства или отказа может дать иной результат. Постановка З13 сохраняется объектной — локализация заданного объекта по образцу (различение и положение вместе), связь и с З10, и с К2; ранжирование готовых детекций вместо координат — другое изменение реализации, его надо называть прямо. Отложенные 75 видео — независимая проверка зафиксированного решения, а не гарантия обнаружения малого прироста (при нынешнем разбросе оракула полуширина ДИ ≈ 0,32 на 35 видео, на 75 — грубо ≈ 0,22). Порог пользы будущей версии записывается заранее и не подгоняется под слабый результат.

Нельзя заявлять, что обученная муха даст +0,33, и нельзя называть +0,33 строгой границей З13. Нельзя заявлять долю общих с MASA исправлений, распределение прироста между потерянными и ведомыми треками, пользу или её отсутствие ночью. Нельзя называть счётчик changed числом поправок, изменивших назначение.
