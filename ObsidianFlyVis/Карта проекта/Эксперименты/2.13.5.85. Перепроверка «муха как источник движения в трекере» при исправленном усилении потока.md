# 2.13.5.85. Перепроверка «муха как источник движения в трекере» при исправленном усилении потока

Состояние: завершён с отрицательным результатом. Код: `fly_gain_tracker_recheck_v1`.

Меняется ли вывод «движение мухи вредит трекеру» при правильном усилении?

val7, 4 видео с кэшем потока мухи (runs/fly_gain_recheck/tracker_injection.json), ByteTrack с подмешиванием движения (вес 1, все треки), средний HOTA: без движения 54,98, DIS 55,27 (0,29), муха при усилении стенда 38,84 — 52,84 (−2,14), при 4 — 54,62 (−0,35), при 1,6 — 54,74 (−0,24); только потерянные треки: 38,84 — 53,76 (−1,22), 1,6 — 54,79 (−0,19).

Вред от мухи при правильном усилении в ~10 раз меньше (−2,1 → −0,2 HOTA), но знак тот же: муха не помогает, DIS помогает слабо. Прежний вывод по знаку верен, по величине — завышен ошибкой усиления.

completed_negative; прежние числа вреда от мухи (при 38,84) считать завышенными; знак вывода сохраняется.

Без доверительного интервала (4 видео); только одна схема подмешивания (ByteTrack без XYWH-стенда).
