# 2.15.2.1. Запись памяти объекта — последнее наблюдение, усреднение и обновление по уверенности

Состояние: неопределённый результат. Код: `query_memory_write_v1`.

Достаточно ли изменить запись памяти при прежних признаках и сопоставлении, чтобы улучшить полный трекер?

runs/continuation_20261029/memory_write_val_audit/report.json: 20 исторических val, четыре новых варианта памяти, полное повторение raw/JSON/событий стоимости/векторов записи памяти/метрик. Старые native/last и точные GPU FP32-векторы переиспользованы по SHA; нового извлечения признаков не было. Все HOTA/AssA/IDF1/FP/FN/IDSw в pooled, четыре парных сравнения с обычными и скорректированными интервалами в primary_comparisons.

Осторожное обновление памяти по уверенности детектора при beta=0,9 ухудшило HOTA относительно последнего наблюдения в обоих извлекателях. Средняя парная разница cautious−last: R50 −0,024644, интервал Bonferroni98,75% [−0,052100; −0,004834]; Detic −0,022980 [−0,050734; −0,003292]. Оба интервала целиком отрицательны. Относительно обычного экспоненциального усреднения оба скорректированных интервала включают ноль. Общий заранее заданный критерий пользы не пройден; положительных подтверждённых сравнений нет. Источник: runs/continuation_20261029/memory_write_val_audit/report.json. Это отрицательный частный результат данной реализации записи, а не доказательство общей причины ошибок памяти.

Эту реализацию усреднения по уверенности не продвигать как улучшение и не подбирать beta по этим val. Сохранить зарегистрированный общий исход inconclusive и явно отрицательные cautious−last сравнения. Рабочая альтернатива для отдельного согласования — решение о записи по неоднозначности назначения вместо одного балла детектора; сначала нужен различающий dev-протокол с согласованным контролем. Ошибочное смешивание личности и устаревание внешности пока не разделены измерением.

Это адаптация отдельного правила записи, не воспроизведение полного Deep OC-SORT и не изменение ядра FlyVis. Уверенность детектора не является меткой личности; медленное обновление может закреплять ошибку. Beta0,9 задана до dev, качество dev не использовалось для выбора варианта. Те же двадцать исторических val не являются новым независимым итоговым тестом. Прежние GPU-векторы переиспользованы точно; их независимая выборочная проверка в девяти точках переиспользована по SHA, это не полный повтор всех пикселей.
