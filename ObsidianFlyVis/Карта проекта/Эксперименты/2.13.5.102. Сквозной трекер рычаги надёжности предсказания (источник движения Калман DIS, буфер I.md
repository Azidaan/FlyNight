# 2.13.5.102. Сквозной трекер: рычаги надёжности предсказания (источник движения Калман/DIS, буфер IoU) и голова надёжности без мухи и с мухой — HOTA на обучающих видео

Состояние: завершён с отрицательным результатом. Код: `e2e_motion_source_v1`.

Даёт ли сигнал надёжности предсказания (и вклад мухи в него) прирост HOTA/IDF1 в самом трекере?

Этап 1 (dev / test / val7, HOTA): стенд 61.336 / 58.469 / 54.573; всегда DIS 61.208 / 57.972 / 53.308; буфер 0,5 61.766 / 59.121 / 54.680 (test: ΔHOTA по видео +0.758 ДИ [+0.251; +1.532], ΔIDF1 ДИ [+0.669; +2.933]). Этап 2: адаптивный буфер 0,3 + 0,8p по голове без мухи 61.818 / 59.208 / 54.642 (над буфером 0,5 на test ДИ [-0.201; +0.206]); та же голова + муха без сетчатки: ΔHOTA test ДИ [-0.023; +0.020]; голова с мухой-ламиной (обучена на 119 train, test 26 роликов с кэшем): ΔHOTA test -0.014 ДИ [-0.037; +0.016], val7 ДИ [-0.034; +0.011].

Рычаг с запасом по HOTA — буфер IoU (заимствованный C-BIoU): +0,65 HOTA и +1,34 IDF1 на test с ДИ > 0. Надёжность предсказания управляет буфером с небольшой пользой (IDF1 dev +0,32 значимо, HOTA — нет). Муха (без сетчатки и с ламиной) в голове надёжности не меняет трекер: её сигнал избыточен относительно рассогласования DIS; рычаг «адаптивный буфер» к тому же слабо чувствителен к качеству головы.

Этап 1 выполнен (буфер > стенда на test, ДИ > 0). Этап 2: «с мухой лучше, чем без мухи» не выполнен ни без сетчатки, ни с ламиной → completed_negative по главному критерию. Практический результат линии B — буфер IoU (+ отложенное рождение, birth_deferred_train_v1). Для мухи — функции без аналога у DIS (Н11).
