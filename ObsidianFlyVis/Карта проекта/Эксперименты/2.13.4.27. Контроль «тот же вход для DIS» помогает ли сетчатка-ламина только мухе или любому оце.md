# 2.13.4.27. Контроль «тот же вход для DIS»: помогает ли сетчатка-ламина только мухе или любому оценщику движения (голова надёжности, тёмные/светлые ролики)

Состояние: завершён с положительным результатом. Код: `dis_retina_control_v1`.

Даёт ли сетчатка-ламина DIS ночью такой же выигрыш, какой она дала мухе?

Тёмные / светлые dev+test, AP: geometry+DIS(исходный) 0.5041 / 0.5227; geometry+DIS(сетчатка) 0.5053 / 0.5228; +муха поверх DIS(сетчатка) 0.5085 / 0.5225. Бутстреп по видео: DIS(сетчатка) − DIS(исходный) — тёмные +0.0012 [-0.0021; +0.0047] (13/14), светлые +0.0001 [-0.0015; +0.0016] (24/19); муха поверх DIS(сетчатка) — тёмные +0.0032 [-0.0013; +0.0078] (15/12), светлые -0.0002 [-0.0033; +0.0028] (22/21); против перемешанного — тёмные +0.0046 [+0.0006; +0.0088] (16/11). Признак DIS здесь пересчитан общим правилом (строки без out_box(t−1) — пропуск), поэтому абсолютные AP ниже, чем в flyvis_retina_stageB_v1 (0,531 против 0,549 на test); сравнения парные.

Сетчатка-ламина не помогает DIS ни ночью (+0,001, ДИ через ноль, 13/14 роликов), ни днём, тогда как той же мухе она ночью дала +0,009 (ДИ > 0, flyvis_retina_stageB_v1). Выигрыш сетчатки специфичен для мухи (её вход был вне обученного распределения), а не общий приём предобработки для любого оценщика движения. Поверх DIS-на-сетчатке муха ночью по-прежнему выше перемешанного контроля.

Оба критерия выполнены → completed_positive: вывод ступени B («сетчатка устраняет ночной провал мухи») защищён от возражения «это просто хорошая предобработка». Ограничение: сетчатка для DIS — в разрешении DIS (×1/4).
