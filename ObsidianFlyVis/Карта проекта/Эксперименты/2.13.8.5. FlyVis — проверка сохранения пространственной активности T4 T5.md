# 2.13.8.5. FlyVis — проверка сохранения пространственной активности T4/T5

Состояние: инфраструктура. Код: `flyvis_full_spatial_capture_probe_v1`.

Можно ли сохранить полные карты T4/T5, сохранив точный прежний выход?

Для одной ранее сохранённой синтетической последовательности штатная FlyVis на CPU повторно вычислена в FP64 с сохранением полных карт восьми типов T4/T5: форма (2, 79, 8, 721); максимальное отличие выхода декодера от сохранённого результата 0, средних активностей 2.5e-16, оба меньше допуска 1e-5. Вычисление и сохранение заняли 9.49 с без учёта загрузки модели; файл 10476641 байт. Параметры неизменны, CUDA не инициализирована. Это техническая проверка, не научный итог и не HOTA. Источники: runs/flyvis_full_spatial_capture_probe_20261105/protocol.json, runs/flyvis_full_spatial_capture_probe_20261105/report.json, runs/flyvis_full_spatial_capture_probe_20261105/independent_audit.json

Сохранение пространственных карт технически возможно для проверенного случая с неизменным выходом.

Использовать как техническое основание, отдельно согласовать научную проверку.

Нет оценки полезности, причин запаздывания, независимых видео или HOTA.
