# 2.13.4.2.3.1.4. Точка отсчёта движения мухи: вычитание отклика после fade-in против абсолютного, установившегося и скользящего

Состояние: завершён с положительным результатом. Код: `fly_reference_point_v1`.

Даёт ли выбор точки отсчёта ложный поток мухи и меняет ли он отклик на известные скорости?

runs/fly_reference_probe/reference.json (24 кадра dev, сдвиг без отражённых краёв, только колонки с источником внутри кадра; наклон — при 1/2/4/8 px/кадр). raw — fadein: ложный поток 1,038 px, наклон −0,008/0,049/0,077/0,098, ошибка/ноль 1,001; absolute: ложный поток 0,675 px, наклон 0,223/0,167/0,138/0,129, ошибка/ноль 0,893; static: ложный поток 0,000 px, наклон 0,110/0,108/0,107/0,113, ошибка/ноль 0,844; ema: ложный поток 0,145 px, наклон 0,086/0,092/0,095/0,102, ошибка/ноль 0,873. lcn24 — fadein: ложный поток 0,033 px, наклон 0,067/0,064/0,062/0,064, ошибка/ноль 0,794; absolute: ложный поток 0,395 px, наклон 0,090/0,078/0,070/0,069, ошибка/ноль 0,880; static: ложный поток 0,000 px, наклон 0,067/0,064/0,062/0,064, ошибка/ноль 0,793; ema: ложный поток 0,005 px, наклон 0,062/0,060/0,058/0,059, ошибка/ноль 0,791. У static ложный поток на неподвижной сцене нулевой по построению.

Точка отсчёта стенда (после fade-in) — изъян для штатного входа: при ней сигнал на малых скоростях почти пропадает (наклон −0,01 при 1 px/кадр), ложный поток наибольший, ошибка равна нулевому движению. При установившейся точке отсчёта отклик мухи линеен по скорости (наклон ≈ 0,11 при всех скоростях — занижение ≈ 9×, исправимое одним множителем); скользящая точка отсчёта (применима к живому видео) снижает ложный поток в 7 раз. С нормализацией контраста точка отсчёта почти не важна (A ≈ C ≈ D) — fade-in на нормализованном входе уже близок к установившемуся состоянию; при этом lcn24 лучше штатного входа и с идеальной точкой отсчёта (0,79 против 0,84). Поправка к fly_noise_probe_v1: ложный поток ±0,6–0,7 px штатного входа — частично от точки отсчёта, а не только от входа.

Критерий 1 выполнен (raw: static/ema снижают ложный поток на ≥ 86 %); критерий 2 не выполнен (на lcn24 ema лучше fadein лишь на 0,003) → для HOTA остаётся точка отсчёта стенда A с lcn24. Отдельный открытый вопрос: даст ли штатный вход + скользящая точка отсчёта на реальных видео выигрыш без нормализации (проверка атрибуции, ≈ 1,5 ч) — по согласованию.

Что результат переносится на реальные видео (искусственный сдвиг); одна модель ансамбля; одна τ скользящей точки отсчёта (1 с).
