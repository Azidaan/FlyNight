# 2.16.2.2.2.1.1. Внешность для возврата номера при естественном пропуске

Состояние: завершён с отрицательным результатом. Код: `gap_appearance_recovery_20261114`.

Можно ли восстановить пропущенную машиной маску по внешности, не выдавая рамки во время разрыва?

На 20 эпизодах естественного пропуска: маска — полностью верно 4/20, при возврате правильных 4, ошибочных 0, неверных во время разрыва 2; внешность — полностью верно 1/20, при возврате правильных 1, ошибочных 1, неверных во время разрыва 1; маска с заполнением пропусков по внешности — полностью верно 4/20, при возврате правильных 4, ошибочных 0, неверных во время разрыва 2. Источник: research_gap_appearance_recovery_20261114/result.json. Когда прошлое наблюдение и правильный текущий кандидат доступны, внешность ставит подходящую рамку на первое место в 6/11 эпизодов. Разница полностью верных последовательностей при дополнении внешностью +0.000 [+0.000; +0.000].

Попадание правильной машины на первое место и безопасная выдача старого номера — разные задачи. Предпочтение внешности само по себе не даёт доказательства, что машина уже появилась.

Не добавлять заполнение пропусков по внешности в рабочий трекер.

Исходная привязка дана по прошлому размеченному кадру, а видео повторно использованы для этой диагностики. Пороги и веса рабочего трекера не затронуты.
