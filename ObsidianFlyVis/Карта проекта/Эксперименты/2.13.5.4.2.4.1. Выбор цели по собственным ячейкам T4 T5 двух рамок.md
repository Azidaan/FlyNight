# 2.13.5.4.2.4.1. Выбор цели по собственным ячейкам T4/T5 двух рамок

Состояние: завершён с отрицательным результатом. Код: `flyvis_exclusive_t4t5_v1`.

Улучшает ли удаление общих колонок из двух рамок выбор правильного продолжения по сохранённым каналам T4/T5?

Основные 26 видео, ровно две допустимые рамки. Из 1368 запросов у 178 известна единственная верная рамка по строгим меткам. У 172 из них обе имеют собственные ячейки. Вся рамка: 104 верных, 0 ничьих, 60,47%; только свои ячейки: 99 верных, 0 ничьих, 57,56%. Разность -2,91 п.п., 95%-й парный интервал по видео [-5,13; -0,93]. В основном сравнении ошибочный выбор стал верным 0 раз, верный стал ошибочным 5 раз. Изменения с ничьей входят в показатель с половинным весом. 23 видео дали оцениваемые пары. Источник: runs/flyvis_exclusive_t4t5_20261107/report.json → comparison.evaluate26.primary.

При данном считывателе исключение общих ячеек ухудшило выбор в проверенных парах.

Сохранить результат диагностики. Изменение штатного сопоставления, новый подбор весов и обучение не выполнялись.

Это выбор между двумя сохранёнными детекциями при заданной цели, а не изменение решений работающего трекера. Использованы нормированные каналы T4/T5 штатной модели и восемь ранее сохранённых коэффициентов наблюдаемой цели. Исторические видео, без обучения, нового прохода модели или HOTA. Уточнение формулировки protocol.inputs: прежний порог уверенности 0,25 отбирал детекции; личности присвоены отдельно, взаимно однозначным сопоставлением с разметкой внутри класса при IoU ≥ 0,5, а не выбором наибольшей уверенности. Использованы готовые метки без изменений.
