Для нынешней области глаза (только ведомые треки, O1) запас от идеализированной поправки положения не достиг принятого порога для продолжения: общий −0,04, по видео −0,003 с ДИ через 0; ночью в среднем даже ниже (−0,26, ДИ через 0). Для узла «глаз сохраняется при потере» (O2) запас достиг порога: общий +0,47, по видео +0,55 [+0,25; +0,89], лучше в 27 из 35; прирост — через связывание (AssA 62,91 → 63,65, IDSw 1 990 → 1 865); ночью +0,28 с ДИ через 0. У потерянных треков O2 применил 4 351 поправку, из них 1 177 — для пар, не проходивших порог первого сопоставления до вмешательства (не число исправленных назначений). Добавление поправок потерянных треков связано с улучшением результата; точный вклад отдельной группы не измерен — O1 и O2 создают разные траектории и последующие решения. Это запас при идеализированном выборе собственной уверенной детекции (по интерполированной разметке) и сдвиге прогноза к её центру, а не результат мухи: FlyVis в опыте не работает, и способность сохранённого состояния мухи найти такую поправку не проверена. Небольшой минус O1 указывает, что сам оракульный сценарий неидеален (размер рамки прежний, ошибки интерполяции, конкуренция треков).

Критерий O2 выполнен — основание подготовить одну рабочую модернизацию FlyVis: сохранять и обновлять фовеальный глаз потерянного трека, чтобы его сигнал поправлял прогноз положения. Рабочая гипотеза (не доказана): непрерывное состояние FlyVis помогает оценивать поправку положения после потери трека. Обязательный контроль — та же FlyVis, тот же глаз и то же считывание без переноса состояния через потерю (повторная инициализация); DIS — дополнительный ориентир, не замена. Протокол, действие и цена — до запуска; GPU — по согласованию. После проверки без сшивки — учесть MASA. Для нынешней области глаза (O1) запас не достиг порога — этот сценарий откладывается.

Нельзя заявлять пользу фовеальной мухи: опыт оракульный, муха не работала. Нельзя заявлять, что поправка ведомых треков бесполезна вообще — проверен один идеализированный сценарий; порог +0,3 — правило расходования ресурсов. Ночной запас O2 не подтверждён (ДИ через 0). Только dev 35; принадлежность на промежуточных кадрах — по интерполированной разметке.
