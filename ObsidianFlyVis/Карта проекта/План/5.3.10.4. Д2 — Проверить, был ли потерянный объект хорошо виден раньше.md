# 5.3.10.4. Д2 — Проверить, был ли потерянный объект хорошо виден раньше

Архивная проверка Д2.

Для реальных потерь на пороге проверить наличие уверенной детекции объекта в предыдущих пяти кадрах. Исходный критерий перехода: такая история есть как минимум у 15 процентов ночных потерь.

Проверка выполнена; критерий пройден. Найдена мишень для восстановления по истории. Следующая простая попытка продолжать треки по прогнозу Калмана не подтвердила пользу: track_continuation_v1.

Не повторять готовый подсчёт. Наличие прошлого наблюдения само по себе не даёт правильного продолжения и старого ID.

Карточка: `past_view_oracle_v1`.
