# 5.3.106.9. К16, подготовка ступени 1: связи FlyWire (FAFB 783) в формате коннектома FlyVis и сверка двух коннектомов

Архивная постановка. Код: `flywire_flyvis_compare_v1`.

**Исход:** инфраструктура · `flywire_flyvis_compare_v1`

Данные FlyWire 783 скачаны по разрешению автора (data/flywire/README.md: 7 файлов, ≈ 283 МБ, публичное хранилище Codex; полная таблица синапсов 9,5 ГБ — ссылкой). scripts/flywire_to_flyvis.py переводит связи правой зрительной доли FlyWire в формат FlyVis (пара типов → смещение колонок → среднее число синапсов на клетку-приёмник), подбирает соответствие осей решётки и сверяет с fib25-fib19_v2.2.json.

## Что сделано
Сопоставление типов, положения клеток, агрегирование связей, подбор осей, сверка по рёбрам; ≈ 5 мин процессора.

## Получено
runs/flywire_flyvis/compare.json, edges.csv, flywire_counts.json. Типов FlyVis найдено в FlyWire 55 из 65; нет: CT1(Lo1), CT1(M10), Mi3, Mi11, Mi12, Tm5Y, Tm28, Tm30, TmY13, TmY18 (соответствия имён: R1–R6 → R1-6, Am → Lai, TmY9 → TmY9q + TmY9q__perp). Клеток с положением: 31 424 (22 314 по привязке к колонкам, 9110 выведено по столбчатым партнёрам); связей правой зрительной доли между ними — 1 150 760 пар, 5 600 789 синапсов. Оси решётки: (p, q) FlyWire → (u, v) FlyVis = ［［0, 1], [1, -1］］ (отражение); средний косинус распределений по смещениям 0,816 против 0,793 у второго преобразования на 230 рёбрах; на 93 несимметричных рёбрах (входы T4/T5 и др.) — 0,696 против 0,646. Рёбер FlyVis с данными FlyWire 469; корреляция логарифмов числа синапсов на клетку 0,697; медиана FlyWire / FlyVis 1,33; медиана косинуса распределений по смещениям 0,868. Рёбер FlyVis, которых в FlyWire практически нет (< 0,5 синапса на клетку): 55; сильных рёбер FlyWire (≥ 5 на клетку), которых нет в FlyVis: 46.

## Интерпретация
Подмена чисел синапсов технически осуществима для 55 из 65 типов; два коннектома согласуются умеренно (корреляция логарифмов 0,70), то есть FlyWire заметно уточняет схему FlyVis: часть рёбер FlyVis в полном объёме практически не подтверждается, а десятки сильных рёбер в FlyVis отсутствуют. Это делает проверку P6 (ступень 1) содержательной.

## Решение
Следующий шаг — собрать flywire_ol_v1.json (рёбра FlyVis с числами FlyWire; не найденные типы и CT1 — числа FlyVis) и контроль с перемешанными числами; дообучение трёх вариантов по протоколу К1 v2 — после итога [fly_finetune_k1_core_v1↗](obsidian://open?vault=ObsidianFlyVis&file=01%20%D0%9C%D1%83%D1%85%D0%B0%2F%D0%AD%D0%BA%D1%81%D0%BF%D0%B5%D1%80%D0%B8%D0%BC%D0%B5%D0%BD%D1%82%D1%8B%2Ffly_finetune_k1_core_v1).

## Нельзя заявлять
Что новые рёбра правильны для модели FlyVis (часть может быть следствием разной разметки типов); соответствие осей подобрано по согласию с FlyVis, а не задано независимо; положения нестолбчатых клеток выведены приближённо.
