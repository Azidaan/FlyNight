# 5.2.5. 4. Что закрыто, и по какому основанию

[4. Что закрыто, и по какому основанию](file:///E:/Dissertation/dissertation/%D0%95%D0%94%D0%98%D0%9D%D0%AB%D0%99_%D0%9F%D0%9B%D0%90%D0%9D.md)

Закрытым считается направление, по которому есть замер с записанным заранее
критерием. Формулировки — по факту замера, а не по впечатлению.

| направление | основание закрытия | число |
|---|---|---|
| DRB v1/v2 (синергия ветвей) | два полных прогона не прошли записанные пороги | ночная mAP50 второго сида внутри разброса контроля |
| Частотная маска FGA | сходится к нейтрали | 4 постановки из 4 |
| Ветвь LQA в затворе | не получала градиента | `w_lqa` = 0 во всех 896 каналах |
| Фиксированный фильтр | на целевой клетке ноль | 0.4158 против 0.4254 ± 0.0144 |
| Карта качества сверх уверенности | вложенное сравнение моделей | +0.0001 при планке 0.0081 |
| То же на пересвете | сильная версия гипотезы | +0.0003 при планке 0.0136 |
| «Компрессор» (динамический диапазон) | мишени нет | −0.0003 при планке 0.0115 |
| Нестабильность назначения в NMS-free | знак обратный ожидаемому | ночью стабильнее дневного |
| «Мелкие теряются из-за разрешения» | удвоение не возвращает половину | +0.025 |
| Адаптация порога трекера по яркости | прирост внутри разброса плеч | 0.096 при разбросе 0.095 |
| Расцепление проходов трекера | выход совпал побайтово | — |
| Гипотеза «ночной дефект — артефакт разрешения» | разрыв надёжности сохранился на 960 | +0.0911 |
| Полоса дрожания 3–8 Гц | подъёма нет, амплитуда меньше пикселя | 0.46 / 0.60 px |
| Ручное вейвлетное очищение траекторий | значимо, но 1–2% → 0.09 IDF1 | +1.98% [0.94, 3.28] |
| Объяснение «порядок движения второй» | предсказание не сбылось | разрыв 0.90% → 0.75% |
| Вклад вейвлетного слоя в обучаемой модели | контроль неотличим | 25.75% против 25.84% |
| **Обучаемый предсказатель движения на лучшей базе** (11.09) | поверх BoT-SORT прирост нулевой и по главной метрике отрицательный | IDF1 −0.26 (−0.4%), mMOTA −0.04 |
| **Вейвлетный слой, третий замер** (11.09) | на 960 и полном val `plain` впереди `wtconv` по mMOTA | 21.34 против 21.25 |
| **Постобработочная коррекция балла** (09.09) | добавление класса, геометрии и состояния сцены не поднимает AUC | 0.9025 → 0.9005; в трекере +0.21 IDF1 |
| **«Цена последнего появления»** (09.09) | разрыв вчетверо меньше, чем у рождения | 5.92 / 9.15 пп против 30.41 |
| **«Место TrackTrack — свойство алгоритма»** (10.09) | при единой рабочей точке он переезжает с последнего места на второе | mMOTA 18.47 → 22.73 |
| **«Подмножество 50 видео смещает метрики»** (10.09) | предположение не подтвердилось, вклад мал | +2.05 mMOTA из 24.13 разрыва |
| **Цель уверенности TAL как причина ночного занижения** (03.10, `threshold_mechanism_iou_v1`, `conf_target_probe_v1`) | при равном IoU разрыв сокращается лишь на 40 % (планка 50 %); дообучение без умножения на IoU ничего не возвращает | ночь −0,15 пп, возраст 0 −0,51 пп при равном FP |
| **Пересчёт слабых кандидатов по тубелету, 5 Гц** (03.10, `temporal_rescore_5hz_v1`) | ложные кандидаты так же устойчивы во времени; правила вредят, голова ≈ база | ночь +1,6 % [−0,6; +3,9] при планке 3 % |
| **Пересчёт по времени и движению относительно фона, 30 Гц** (03.10, `motion_rescore_30hz_v1`) | тубелет 30 Гц + DIS-гомография лишь догоняют балл YOLO26 | dev+test −0,1 % [−3,8; +3,0] при планке 3 % |

Отдельно: **фазы 1–3 плана NoManNight (частотный рельс, WTConv в детекторе)**
закрыты не провалом, а арифметикой мишени — они целятся в ступень слепоты 4.5%,
которая ночью не хуже дневной, тогда как весь ночной дефицит сидит в ступени
порога (21.0% против 15.5%).
