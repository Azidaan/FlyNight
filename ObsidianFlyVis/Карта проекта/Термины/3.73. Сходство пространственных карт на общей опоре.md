# 3.73. Сходство пространственных карт на общей опоре

По каждому каналу вычитается среднее на фиксированном наборе ячеек. Скалярное произведение всех центрированных значений делится на произведение норм. При нулевой норме оценка не определена.

Большое значение означает большее сходство карт, в том числе при ошибочном совпадении.
