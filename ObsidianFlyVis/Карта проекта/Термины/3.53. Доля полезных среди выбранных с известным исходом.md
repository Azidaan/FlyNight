# 3.53. Доля полезных среди выбранных с известным исходом

В каждом видео выбираются ceil(0,05*N) строк из всех N по баллу считывателя без использования исхода. Доля полезных считается среди выбранных строк с известной разметкой; затем среднее по видео.

Не HOTA и не гарантия отказа. Неизвестные исходы отдельно; изменение их доли может влиять на сравнение. Квота по каждому видео отличается от прежнего общего5%отбора.
