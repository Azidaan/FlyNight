# 3.31. AUROC соответствия известных областей

Площадь под ROC-кривой бинарной оценки одного объекта по паре областей; только пары с известной личностью обоих концов.

Условная диагностика пар,не сохранение личности полного трекера и не HOTA. Зависимые пары требуют повидео сравнения для научного вывода.
