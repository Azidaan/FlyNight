# 3.61. Охват причинно доступных пар областей

Доля исходных запросов, для которых есть поддержанные реальные области в текущем и строго предыдущем наблюдении. Не качество памяти модели.

Знаменатель и правило выбора прошлого обязательны; численные признаки FlyVis этим не проверяются.
