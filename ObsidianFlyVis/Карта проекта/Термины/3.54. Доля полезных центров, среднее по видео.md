# 3.54. Доля полезных центров, среднее по видео

Для каждого видео: доля положительных случаев, в которых оценённый центр точнее прогноза и проходит фиксированный порог ошибки; затем среднее по видео.

Это локализация заданной потерянной цели, не HOTA и не точность среди выбранных вмешательств; неизвестные исходы отдельно.
