# 3.75. Чистая польза выбора рамочного действия

Средняя по видео разность числа полезных и вредных выбранных действий,делённая на все известные исходные запросы каждого видео.

Не HOTA; неизвестные случаи отдельно,все известные остаются в знаменателе. Для парного сравнения фиксируются действия,состояния,видео,сид иразбиение.
