# 3.42. J — правильные минус чужие назначения

На заранее закреплённых запросах число конечных назначений правильной размеченной машины запрошенному потерянному ID минус число назначений другой известной машины. Неназначение даёт ноль. Неизвестная личность даёт ноль и учитывается отдельно.

Условная разработческая диагностика однокадрового вмешательства из исходного состояния. Не является HOTA, доказательством длительного сохранения личности или отсутствия вреда конкурентам; обе поисковые рамки могут быть чужими при наличии цели вне пары.
