## 04:23 постановка окна прогноза внутри считывания `z13_motion_window_v1`

*Постановка.* Replace unrestricted map maximum by a forecast-centered cosine-window preference over all721columns inside the FlyVis readout. Keep original local7-neighbor center weighting and raw peak confidence unchanged. This is not confidence filtering or core training.

Response density=(map-min)/sum(map-min), uniform if flat. Hann window: product overx,y of0.5*(1+cos(2*pi*clip((point-forecast_eye)/eye_size,-0.5,0.5))), normalized to sum1. If window has no support use response itself. Blend densities (1-a)*response+a*window for selecting a column only. Original raw-map local weights around the selected column; a=0 exactly old center/confidence.

Only previous20 training videos; fixed influences[0,.125,.25,.5,.75,1]. Select highest per-video useful mean per arm, first grid choice on exact ties. No new seed, core, normalization, ridge lambda, candidate feature fitting or evaluation26 tuning.

Критерии до исходов: C_window-C_top1: mean>=0.02 and paired-video95%lower>0. C_window-C_nearest3, C_window-C_BCE104 and C_window-R1_window: all lower>0. All conditions required; D secondary cannot rescue. R1 effect and Cgain-R1gain always reported.

Опора: Bertinetto et al.2016, раздел2.4, https://arxiv.org/html/1606.09549v2 — косинусное окно на карте; наша версия использует прогноз Калмана и прежнюю2x вырезку, это не воспроизведение SiamFC. Главный контраргумент: A spatial window can merely reproduce motion prediction or prefer tiny apparent corrections, without recognizing the target. Full-column choices differ from the old3-peak set. Nearest3 and the existing BCE104 map-reading node are required controls; pixel/relative errors are reported, not only useful fraction.

If train26 gate fails, stop this window variant without dev. If it passes, freeze influence values and separately register conditional fixed dev35 full-map extraction under the remaining original morning window before any dev calculation. No dev retuning or protected75. CPU до600с; нового прохода ядра не требуется.
