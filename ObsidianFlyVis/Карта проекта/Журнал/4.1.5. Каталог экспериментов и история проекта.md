# 4.1.5. Каталог экспериментов и история проекта

Дата: 2026-09-14.

## 23:45 окно «История проекта»: эксперименты, коммиты,

хронология плана, словарь метрик.

*Файлы.* Новые: пакет `evaluation/project_history/` (model, safe_paths,
git_reader, plan_parser, catalog, artifacts, index, filters, render),
`scripts/project_history_window.py`, `ui/project_history.html`,
`experiments/project_history.json` (17 направлений, 22 карточки),
`experiments/metrics_glossary.json` (32 метрики, 21 термин),
`scripts/validate_project_history.py`, `tests/test_project_history.py`,
`AGENTS.md`. Изменены: `Запусти меня.py` (метод `open_history`),
`ui/launcher.html` (кнопка «История проекта»), этот журнал.

*Реализовано.* Отдельное окно только для чтения по образцу окна результатов:
вкладки «Обзор», «Эксперименты», «Коммиты», «Хронология», «Ожидалось —
сделано», «Единый план», «Словарь». Git читается только командами чтения
(hash проверяется регулярным выражением и `cat-file -e`), diff ограничен
200 КБ, пути открываются только внутри проекта через `Path.resolve()` и
`relative_to`. План разбирается по заголовкам, таблицам, хронологии раздела 2
и этому журналу; hash в обратных кавычках связывает запись с коммитом.
Кураторский каталог хранит «ожидалось / сделано / получено / решение», десять
состояний, критерии приёмки и доказательства ссылками; каждое число — с
адресом в JSON/CSV, индексатор сверяет его с источником. У каждой метрики
подсказка «?» из словаря; метрика без описания — ошибка каталога. Фильтры
(И): текст, направление, состояние, результат, даты, коммит / метрики /
артефакты, источник, сид, детектор, трекер, данные, условие. Кэш индекса —
`.cache/project_history/index.json` по отпечатку HEAD, плана, каталога,
словаря и отчётов; состояние рабочей директории в кэш не пишется.
Коммит `3472a05` («Tracker 1,0») показан как пустая метка: в нём 0 файлов.

`scripts/validate_project_history.py --strict` — OK, все локаторы чисел
