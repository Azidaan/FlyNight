# Отпечаток мухи

↑ [[01 Муха/Муха (FlyVis)|Муха]]

Отпечаток (сигнатура) — сводка активности 34 выходных типов глаза мухи за начало и конец жизни трека. По нему решается «тот же объект или другой» при сшивке обрывков треков.

- Отпечаток мухи несёт идентичность: к геометрии +0,14 AP — [[fly_signature_reid_v1|Н11: сигнатура состояния фовеального глаза FlyVis (с сетчаткой-ламиной) для повторного опознания объекта после потери трека]].
- Но почти вся информация уже есть во входе глаза: поверх входа муха добавляет +0,006 (ночью +0,010) — [[fly_matched_controls_v1|Н11, контроль того же объёма информации: схема мухи против её собственного входа (721 фасетка, то же поле зрения) и разрез по времени суток]].
- Сшивка треков по одной геометрии даёт +0,79 HOTA, внешность и муха сверх неё незначимы — [[stitch_appearance_v1|Офлайн-сшивка треков стенда по голове повторного опознания (геометрия + внешность + вход глаза) — HOTA/IDF1/IDSw на обучающих видео]].
