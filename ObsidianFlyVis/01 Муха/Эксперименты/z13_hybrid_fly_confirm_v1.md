# 🟢 Проверка вклада FlyVis в гибридное узнавание цели на train26 — замороженная версия v2, одна оценка

↑ [[01 Муха/Темы/Прочее о мухе|Прочее о мухе]] · **Исход:** отрицательный · `z13_hybrid_fly_confirm_v1`

Одна оценка на train26 замороженной конфигурации [z13_hybrid_identity_v2↗](obsidian://open?vault=ObsidianFlyVis&file=01%20%D0%9C%D1%83%D1%85%D0%B0%2F%D0%AD%D0%BA%D1%81%D0%BF%D0%B5%D1%80%D0%B8%D0%BC%D0%B5%D0%BD%D1%82%D1%8B%2Fz13_hybrid_identity_v2), зарегистрированная до вычисления любых чисел train26 для этой конфигурации. Обучение на fit84, порог по fit20, оценка на train26.

## Вопрос
Подтверждается ли на других видео прибавка ветви FlyVis D к базовой ветви внешнего вида и её преимущество над входом глаза R1, найденные на fit104?

## Гипотеза
Рабочая гипотеза: на fit104 база + D − база = +0,409 п.п. [+0,134; +0,687], база + D − база + R1 = +0,430 [+0,086; +0,796] (runs/z13_hybrid_identity_v2_20261026/internal_report.json). Альтернатива: это следствие множества сравнений на повторно использованных fit104, и на train26 прибавки не будет.

## Ожидалось (до прогона)
Протокол runs/z13_hybrid_fly_confirm_20261026/protocol.json, скрипт scripts/z13_hybrid_fly_confirm_20261026.py. Признаки train26 строятся тем же кодом, что и кэш fit104; PCA только по fit104. Плечи: база, база + D, база + C, база + R1, истинная личность. Только CPU, Idle, срок 27.10 07:30 МСК. Повторной настройки после просмотра нет.

## Интерпретация
Прибавка ветви FlyVis D к внешнему виду, найденная на fit104 (+0,409 п.п.), на train26 не воспроизвелась: +0,107 с границей −0,176; D не лучше входа глаза R1 (−0,042) и штатной C (−0,095). Значит, эффект на fit104 был следствием множества сравнений на повторно использованных видео. Воспроизвелась только польза внешнего вида MASA: база без мухи +0,660 [+0,035; +1,302] к стенду — это улучшение трекера, не FlyVis (правило 6.16). Общий порог +2 п.п. не пройден (база + D +0,767, около 27% потолка истинной личности +2,836).

## Решение
Вклад FlyVis в гибридное узнавание не подтверждён; в подтверждённые результаты не вносить. Гипотеза «ветвь D добавляет к внешнему виду MASA» закрыта по заранее записанному критерию; узел провала прежний — сохранённые признаки мухи не различают цель среди похожих соседей сверх того, что уже даёт внешний вид. Дальше — менять само представление мухи (дообучение ядра на узнавание, scripts/z13_core_identity_20261026.py, GPU-часы) только по решению автора.

## Нельзя заявлять
Не HOTA. Нельзя заявлять вклад FlyVis в узнавание цели. Польза внешнего вида (+0,66 п.п., нижняя граница +0,035) — не результат мухи, мала и получена на train26, которые многократно использовались прежними опытами. 26 видео; одна оценка.
