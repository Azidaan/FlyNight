# 🟢 Контроль «тот же вход для DIS»: помогает ли сетчатка-ламина только мухе или любому оценщику движения (голова надёжности, тёмные/светлые ролики)

↑ [[01 Муха/Темы/Глаз и сетчатка-ламина|Глаз и сетчатка-ламина]] · **Исход:** положительный · `dis_retina_control_v1`

Методическая дыра, найденная обзором research_project_now (тема C5): сетчатку М1 не подавали на вход DIS, хотя М1 это планировал. scripts/build_dis_retina.py: DIS (пресет MEDIUM, шаг 8, ×1/4) на кадрах после ламины, применённой в разрешении DIS (σ 24→6, 12→3 px), сетка точек совпадает с dis_quarter (проверено); признак рассогласования DIS пересчитан одной и той же функцией из исходного DIS и из DIS-на-сетчатке (перенос out_box(t−1) того же трека; строки без него — NaN в обоих вариантах). Лестница Н2 (scripts/evaluate_motion_reliability.py) дважды: geometry+DIS(исходный) и geometry+DIS(сетчатка), муха-ламина одна и та же; разрез dev+test по яркости < 60/255.

## Вопрос
Даёт ли сетчатка-ламина DIS ночью такой же выигрыш, какой она дала мухе?

## Гипотеза
Если выигрыш сетчатки специфичен для мухи, DIS-на-сетчатке на тёмных роликах не лучше исходного DIS, а «+DIS+муха» поверх него сохраняет вклад мухи.

## Ожидалось (до прогона)
На тёмных dev+test роликах: AP geometry+DIS(сетчатка) − geometry+DIS(исходный) — ДИ задевает ноль или < 0 (сетчатка не помогает DIS); при этом вклад мухи поверх DIS(сетчатка) на тёмных не исчезает (≥ 0). Если DIS(сетчатка) значимо лучше ночью — вывод ступени B смягчается: сетчатка — общий приём предобработки, а не свойство мухи.

## Что сделано
Карточка записана до результата (01.10.2026, 03:0x MSK). Упрощение: сетчатка для DIS — в разрешении DIS (×1/4), а не на полном кадре, как для мухи. Расчёт 01.10 03:0x–07:45 (компьютер простаивал ~03:10–07:20, в системном журнале — смена времени в 06:27; данные не потеряны). Отчёты: runs/dis_retina/h2_orig/report.json, runs/dis_retina/h2_lamina/report.json, runs/dis_retina/strata_bootstrap.json.

## Получено
Тёмные / светлые dev+test, AP: geometry+DIS(исходный) 0.5041 / 0.5227; geometry+DIS(сетчатка) 0.5053 / 0.5228; +муха поверх DIS(сетчатка) 0.5085 / 0.5225. Бутстреп по видео: DIS(сетчатка) − DIS(исходный) — тёмные +0.0012 [-0.0021; +0.0047] (13/14), светлые +0.0001 [-0.0015; +0.0016] (24/19); муха поверх DIS(сетчатка) — тёмные +0.0032 [-0.0013; +0.0078] (15/12), светлые -0.0002 [-0.0033; +0.0028] (22/21); против перемешанного — тёмные +0.0046 [+0.0006; +0.0088] (16/11). Признак DIS здесь пересчитан общим правилом (строки без out_box(t−1) — пропуск), поэтому абсолютные AP ниже, чем в [flyvis_retina_stageB_v1↗](obsidian://open?vault=ObsidianFlyVis&file=01%20%D0%9C%D1%83%D1%85%D0%B0%2F%D0%AD%D0%BA%D1%81%D0%BF%D0%B5%D1%80%D0%B8%D0%BC%D0%B5%D0%BD%D1%82%D1%8B%2Fflyvis_retina_stageB_v1) (0,531 против 0,549 на test); сравнения парные.

## Интерпретация
Сетчатка-ламина не помогает DIS ни ночью (+0,001, ДИ через ноль, 13/14 роликов), ни днём, тогда как той же мухе она ночью дала +0,009 (ДИ > 0, [flyvis_retina_stageB_v1↗](obsidian://open?vault=ObsidianFlyVis&file=01%20%D0%9C%D1%83%D1%85%D0%B0%2F%D0%AD%D0%BA%D1%81%D0%BF%D0%B5%D1%80%D0%B8%D0%BC%D0%B5%D0%BD%D1%82%D1%8B%2Fflyvis_retina_stageB_v1)). Выигрыш сетчатки специфичен для мухи (её вход был вне обученного распределения), а не общий приём предобработки для любого оценщика движения. Поверх DIS-на-сетчатке муха ночью по-прежнему выше перемешанного контроля.

## Решение
Оба критерия выполнены → completed_positive: вывод ступени B («сетчатка устраняет ночной провал мухи») защищён от возражения «это просто хорошая предобработка». Ограничение: сетчатка для DIS — в разрешении DIS (×1/4).

## Ограничения
Сетчатка для DIS в разрешении ×1/4; один набор параметров сетчатки.
