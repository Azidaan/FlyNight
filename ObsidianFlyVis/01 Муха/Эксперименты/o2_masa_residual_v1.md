# 🟢 Остаток запаса оракула O2 после сшивки MASA (проверка перед З13)

↑ [[01 Муха/Темы/Прочее о мухе|Прочее о мухе]] · **Исход:** положительный · `o2_masa_residual_v1`

## Вопрос
Сколько из запаса оракула O2 (fovea_target_30hz_v1: +0,47 HOTA без сшивки) остаётся после сшивки MASA стенда — то есть сколько может взять З13 (обученное объектное считывание мухи) поверх нынешнего лучшего выхода?

## Гипотеза
Оракул O2 возвращает потерянный трек к детекции его собственного объекта (знание разметки); MASA сшивает обрывки по внешности после трекера. Если это во многом одни и те же случаи, остаток после MASA мал и З13 не даст пользы стенду при любом качестве мухи.

## Ожидалось (до прогона)
Критерий (до прогона, решение автора 12.10 по правилу 6.16): dev 35, HOTA выхода после MASA с оракулом O2 − выход после MASA стенда (runs/chain_filter_rank/repro/dev, 61,655): общий прирост ≥ +0,3 и ДИ по видео > 0 (бутстрэп 5000) — З13 оправдана к одной реализации; иначе З13 остаётся задумкой, обучение не начинается. Сверка до сравнения: выход O2 без сшивки, собранный новым сборщиком, воспроизводит 61,807 (runs/fovea_target_30hz/report.json, pooled O2|all). Справочно: ночь; O2 без сшивки − стенд без сшивки. Оракул читает разметку — это потолок, не реализуемый метод.

## Интерпретация
Запас оракула O2 после сшивки MASA остаётся на 71 % (+0,333 из +0,471 без сшивки): MASA и оракул в основном исправляют разные случаи, пересечение ≈ +0,14. Остаток почти целиком — короткие разрывы: число длинных разрывов после MASA почти не меняется (401 → 395), всех — 2144 → 2066; оракул действует в пределах буфера 30 кадров. Ночью остаток мал и не отличим от нуля (+0,141, ДИ включает 0) — ночная ниша длинных разрывов к этому запасу не относится. Критерий выполнен на грани: общий +0,333 при пороге +0,3.

## Решение
По заранее записанному критерию З13 оправдана к одной реализации; запуск обучения — решение автора. Потолок для З13 поверх стенда с MASA — +0,33 HOTA при знании разметки; реализуемая версия возьмёт часть, и прирост около +0,1 на dev 35 от нуля не отличить — до реализации нужно записать порог пользы с учётом этой чувствительности. Задача З13 по устройству оракула — выбрать свою детекцию для потерянного трека в пределах буфера (узнавание при коротком разрыве), а не уточнить центр.

## Нельзя заявлять
Нельзя заявлять, что обученная муха даст +0,33: это потолок оракула, читающего разметку. Нельзя заявлять пользу ночью. Пересечение с MASA оценено разностью итогов, без разбора по отдельным разрывам.
