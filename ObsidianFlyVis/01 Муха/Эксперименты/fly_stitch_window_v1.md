# 🟢 Сшивка обрывков в расширенном окне кандидатов (150 кадров, 5 размеров рамки) с порогом по dev

↑ [[01 Муха/Темы/Прочее о мухе|Прочее о мухе]] · **Исход:** отрицательный · `fly_stitch_window_v1`

[fly_stitch_oracle_v1↗](obsidian://open?vault=ObsidianFlyVis&file=01%20%D0%9C%D1%83%D1%85%D0%B0%2F%D0%AD%D0%BA%D1%81%D0%BF%D0%B5%D1%80%D0%B8%D0%BC%D0%B5%D0%BD%D1%82%D1%8B%2Ffly_stitch_oracle_v1): идеальная сшивка в нынешнем окне (60; 3) +2,27 HOTA test, в окне (150; 5) +2,98, (300; 8) +3,11; реальная сшивка по геометрии в окне (60; 3) +0,84 (stitch_appearance_v1). Здесь — та же процедура scripts/eval_fly_reid.py (головы лестницы на train, порог на dev по IDF1 из {0,1; 0,15; 0,2; 0,3; 0,4; 0,5}, проверка test 35 и val7) в окне (150; 5).

## Вопрос
Даёт ли расширение окна кандидатов прирост HOTA реальной сшивки?

## Гипотеза
В окне (150; 5) реальная сшивка забирает больше запаса, чем в (60; 3).

## Ожидалось (до прогона)
test: лучшая голова в окне (150; 5) − без сшивки > +0,84 (результат окна 60; 3), парная разность с окном (60; 3) по видео > 0, ДИ > 0; val7 — тот же знак.

runs/fly_reid_w150/report.json (stitch, stitch_bootstrap), сравнение с окном (60; 3) — runs/fly_reid/report.json (stitch.*.per_video). Без сшивки test HOTA 58,469. Окно (150; 5), порог по dev 0,3: stitch_geo test 59,009 (+0,563 [0,104; 1,147]), stitch_app 59,205, stitch_base 59,132 (+0,596 [0,021; 1,250]), stitch_fly 59,197 (+0,652 [0,110; 1,275]); val7 stitch_fly +0,485 [0,141; 1,021]. Муха сверх базы в окне 150: test +0,056 [−0,029; 0,159], val7 +0,057 [0,017; 0,105]. AP «та же жизнь» (с утечкой кандидатов): L_app_hexin_fly test 0,5714 против L_app_hexin 0,5548.

## Интерпретация
Идеальная сшивка выигрывает от расширения окна (+2,27 → +2,98), реальная — нет: кандидатов втрое больше (test 32178 → 102894), точность головы падает, и запас не забирается. Узкое место — не окно, а различение пар головой (замена узла «внешность» — [stitch_appearance_models_v1↗](obsidian://open?vault=ObsidianFlyVis&file=01%20%D0%9C%D1%83%D1%85%D0%B0%2F%D0%AD%D0%BA%D1%81%D0%BF%D0%B5%D1%80%D0%B8%D0%BC%D0%B5%D0%BD%D1%82%D1%8B%2Fstitch_appearance_models_v1)). Оговорка: все числа сшивки этой карточки и окна 60 получены со списком кандидатов, отфильтрованным по разметке (утечка, найдена 08.10) — абсолютные приросты завышены; сравнение окон между собой — при одинаковой утечке.

## Решение
Окно (60; 3) остаётся рабочим для текущих голов; расширение окна вернуть после замены внешности (DINOv3-S / MASA-R50) — в [stitch_appearance_models_v1↗](obsidian://open?vault=ObsidianFlyVis&file=01%20%D0%9C%D1%83%D1%85%D0%B0%2F%D0%AD%D0%BA%D1%81%D0%BF%D0%B5%D1%80%D0%B8%D0%BC%D0%B5%D0%BD%D1%82%D1%8B%2Fstitch_appearance_models_v1) окно (150; 5) проверяется уже без утечки.

## Нельзя заявлять
Нельзя заявлять прирост головы по геометрии (+0,56): он держался на отборе кандидатов по разметке. Поправка 08.10 (stitch_appearance_models_v1): для голов с внешностью утечка прирост не завышала — без неё база +0,67 (runs/stitch_v2/gap150_dist5/report.json, stitch.base).
