# 🔴 Гибридное узнавание цели — базовая ветвь внешнего вида MASA и ветвь FlyVis, решение о переносе рамки

↑ [[01 Муха/Темы/Прочее о мухе|Прочее о мухе]] · **Исход:** отрицательный · `z13_hybrid_identity_v1`

Решение автора 26.10.2026 (~19:00): цель — решить проблему узнавания цели среди похожих соседей, допускается выход за пределы мухи; по образцу схемы «базовая ветвь + ветвь с мухой». Базовая ветвь — признаки внешнего вида MASA-R50 для реальных областей и для наблюдаемого образца цели; ветвь мухи — признаки FlyVis v3. Вклад мухи измеряется отдельно: база против база + муха.

## Вопрос
Решает ли базовая ветвь внешнего вида узнавание цели настолько, чтобы двухступенчатое решение дало ≥ +2 п.п. чистой пользы, и добавляет ли ветвь FlyVis пользу сверх базы?

## Гипотеза
Рабочая гипотеза: устройство решения проверено (с истинной личностью +2,93 п.п. [2,38; 3,47], [z13_identity_gate_readout_v1↗](obsidian://open?vault=ObsidianFlyVis&file=01%20%D0%9C%D1%83%D1%85%D0%B0%2F%D0%AD%D0%BA%D1%81%D0%BF%D0%B5%D1%80%D0%B8%D0%BC%D0%B5%D0%BD%D1%82%D1%8B%2Fz13_identity_gate_readout_v1)); не хватает различения похожих соседей, а MASA по проекту различает объекты (тот же трек 0,955, разные 0,103 — scripts/build_masa_embeddings.py). Альтернатива: на трудных запросах внешний вид тоже неразличим (похожие машины, ночь, перекрытие), либо рамка образца по маске глаза слишком неточна.

Плечи узнавания: база (сходство области с образцом, с помеченной прошлой целью, с накопленным образом + относительные версии + геометрия), база + D, база + C, база + R1, только D (v3), истинная личность. ## Интерпретация
Внешний вид улучшил узнавание цели (AUC 0,964 → 0,972 с D) и впервые дал положительную нижнюю границу пользы против исходного назначения (+0,614 п.п.), но до порога +2 п.п. далеко (около 21% потолка истинной личности). Прибавка FlyVis к внешнему виду +0,259 п.п. с нижней границей −0,025 — неопределённа; D не отличается от штатной C. Узнавание остаётся узким местом: точность переносов около 56% против 67% у истинной личности.

## Решение
Критерий решения проблемы (≥ +2 п.п.) не пройден, вклад мухи не подтверждён; train26 не оценивать. Сохранить как лучший на сейчас вариант пути назначения. Следующая замена в базовой ветви — точнее и богаче память внешнего вида (рамка образца, привязанная к наблюдаемой детекции; обучаемое сравнение векторов внешнего вида), с теми же контролями.

## Нельзя заявлять
Не HOTA. +0,614 п.п. — на повторно использованных fit104, условные интервалы, без поправки на множественность сравнений этой ночи; это не подтверждённый результат для витрины. Польза получена в основном внешним видом MASA (улучшение трекера), вклад FlyVis не доказан; MASA уже применяется стендом при сшивке.
