# 🟢 Д5: держатся ли выводы о мухе на других моделях ансамбля FlyVis (012, 025, 037 против 000)

↑ [[01 Муха/Темы/Устойчивость выводов — ансамбль|Устойчивость выводов — ансамбль]] · **Исход:** положительный · `fly_ensemble_members_v1`

Из research_fundamental_problems (F13): все выводы о мухе получены на одной модели ансамбля flow/0000/000 (лучшая по Sintel, 5,137). Повтор цепочки сигнатур повторного опознания (scripts/build_fly_signatures.py, сетчатка-ламина, те же 147 роликов, трекер и пары, что у [fly_signature_reid_v1↗](obsidian://open?vault=ObsidianFlyVis&file=01%20%D0%9C%D1%83%D1%85%D0%B0%2F%D0%AD%D0%BA%D1%81%D0%BF%D0%B5%D1%80%D0%B8%D0%BC%D0%B5%D0%BD%D1%82%D1%8B%2Ffly_signature_reid_v1) / [fly_connectome_null_v1↗](obsidian://open?vault=ObsidianFlyVis&file=01%20%D0%9C%D1%83%D1%85%D0%B0%2F%D0%AD%D0%BA%D1%81%D0%BF%D0%B5%D1%80%D0%B8%D0%BC%D0%B5%D0%BD%D1%82%D1%8B%2Ffly_connectome_null_v1)) на моделях 012 (5,278), 025 (5,301, медиана), 037 (5,333); лестница голов scripts/eval_fly_reid.py --ladder-only. Главная проверяемая заявка — вклад мухи поверх её входа (geometry + вход + муха − geometry + вход) и муха к геометрии.

## Вопрос
Воспроизводятся ли «муха к геометрии +0,14 AP» и «муха поверх входа +0,006» на других моделях ансамбля?

## Гипотеза
Знак обоих эффектов одинаков у всех 4 моделей; величина в пределах разброса между моделями.

## Ожидалось (до прогона)
Знак «geometry + вход + муха − geometry + вход» на test тот же у ≥ 3 из 3 новых моделей (с 000 — 4 из 4); «geometry + муха − geometry» > 0 у всех. Если знак расходится — заявки о мухе относятся к модели 000, а не к FlyVis.

## Что сделано
Сборка сигнатур трёх моделей (012, 025, 037) × 147 роликов — scripts/run_fovea_jobs.py, 3 процесса с мьютексом GPU, 04.10 16:58 – 05.10 04:47, 441 задание без сбоев; лестница голов scripts/eval_fly_reid.py --ladder-only по каждой модели; сравнение scripts/compare_ensemble_members.py (двухуровневый бутстреп: модели → видео).

## Получено
AP, модели 000 / 012 / 025 / 037. Муха к геометрии: test +0,1067 / +0,1353 / +0,1168 / +0,1468; ансамбль +0,1264 [+0,0883; +0,1670], знак 4/4; dev +0,1132 / +0,1150 / +0,1062 / +0,1205; ансамбль +0,1138 [+0,0856; +0,1418], знак 4/4; val7 +0,0577 / +0,0586 / +0,0578 / +0,0681; ансамбль +0,0605 [-0,0184; +0,1332], знак 4/4. Муха поверх входа: test +0,0060 / +0,0067 / +0,0034 / +0,0064; ансамбль +0,0056 [+0,0004; +0,0115], знак 4/4; dev +0,0086 / +0,0091 / +0,0057 / +0,0063; ансамбль +0,0074 [+0,0005; +0,0164], знак 4/4; тёмные +0,0102 / +0,0154 / +0,0035 / +0,0124; ансамбль +0,0104 [+0,0012; +0,0235], знак 4/4; светлые +0,0054 / +0,0033 / +0,0052 / +0,0026; ансамбль +0,0041 [+0,0001; +0,0080], знак 4/4; val7 +0,0065 / +0,0016 / +0,0034 / +0,0028; ансамбль +0,0036 [-0,0067; +0,0136], знак 4/4.

## Интерпретация
Выводы о мухе держатся на ансамбле FlyVis: знак обоих эффектов одинаков у всех четырёх моделей во всех десяти разрезах, двухуровневый бутстреп (модели → видео) даёт ДИ > 0 на test, dev, тёмных и светлых видео. Модель 000 — не лучшая, а средняя (037 сильнее). Ночной вклад мухи поверх входа больше дневного у трёх моделей из четырёх. На val7 (7 видео) ДИ проходит через ноль у всех.

## Решение
Оба критерия выполнены → completed_positive. Заявки «отпечаток мухи несёт идентичность» и «муха добавляет поверх своего входа, ночью больше» — свойство ансамбля, не одной модели. Проблема P7 («все выводы на одной модели») решена; дальнейшие опыты с мухой — минимум на 3 моделях.

## Нельзя заявлять
Что выводы держатся для любого набора параметров FlyVis: проверены 4 из 50 моделей (без крайних по ошибке Sintel); val7 — ДИ через ноль.

- **dataset:** те же 147 роликов (train 130 → dev/test 35, val7), runs/fly_signatures_m{012,025,037}[_val]
