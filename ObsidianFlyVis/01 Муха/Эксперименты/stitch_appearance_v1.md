# 🟢 Офлайн-сшивка треков стенда по голове повторного опознания (геометрия + внешность + вход глаза) — HOTA/IDF1/IDSw на обучающих видео

↑ [[01 Муха/Темы/Отпечаток мухи и опознание|Отпечаток мухи и опознание]] · **Исход:** положительный · `stitch_appearance_v1`

Побочный результат [fly_signature_reid_v1↗](obsidian://open?vault=ObsidianFlyVis&file=01%20%D0%9C%D1%83%D1%85%D0%B0%2F%D0%AD%D0%BA%D1%81%D0%BF%D0%B5%D1%80%D0%B8%D0%BC%D0%B5%D0%BD%D1%82%D1%8B%2Ffly_signature_reid_v1). Пары «жизнь трека закончилась → другой трек родился через 1…60 кадров не дальше 3 размеров»; голова (логистическая регрессия: разрыв, расстояние, размер, класс, косинус картинок 16×16, L1 HSV-гистограмм, косинус входа глаза мухи) учится на 70 train-роликах; сшивка жадно один к одному при p > порога, связь запрещена, если у цепочек есть общие кадры. Порог — максимум IDF1 на dev из {0,2; 0,3; 0,4; 0,5; 0,7}. Заимствовано по идее: AFLink (StrongSORT, Du et al., 2023) — офлайн-связывание треков; своя реализация и признаки.

## Вопрос
Сколько дают стенду офлайн-связывание обрывков треков по простой внешности?

## Гипотеза
Много переключений ID стенда — это обрывы трека с новым рождением рядом; простая внешность их связывает.

Критерии до прогона не записывались (результат получен как этап 3 карточки [fly_signature_reid_v1↗](obsidian://open?vault=ObsidianFlyVis&file=01%20%D0%9C%D1%83%D1%85%D0%B0%2F%D0%AD%D0%BA%D1%81%D0%BF%D0%B5%D1%80%D0%B8%D0%BC%D0%B5%D0%BD%D1%82%D1%8B%2Ffly_signature_reid_v1) — базовая голова без мухи). ## Интерпретация
Значимая часть переключений ID стенда — обрывы трека с новым рождением поблизости в течение 2 с; простая внешность (картинка, цвет, вход глаза) и геометрия связывают их надёжно: IDSw ниже на всех 35 роликах, HOTA и IDF1 растут и на test, и на val7. Абляция: почти весь прирост (+0,79 из +0,84 HOTA test) даёт одна геометрия; внешность (+0,08) и вход глаза (−0,04) незначимы. AP пар (геометрия 0,438 против 0,686 с внешностью) почти не предсказывает HOTA: жадная сшивка с низким порогом меняет считаные связи.

## Решение
Сшивка по одной геометрии — самый дешёвый и почти полный вариант (не требует ни мухи, ни внешности); внешность оставить опцией. Порог 0,2 на краю сетки — проверить ниже; совместить с каскадом буферов.

## Ограничения
Порог на краю сетки; один сид; признак «вход глаза» требует прогона глаза мухи (для чистой линии B можно оставить только картинку и цвет — не проверено отдельно).

## Нельзя заявлять
Новизну метода: офлайн-связывание треков известно (AFLink, GSI).
