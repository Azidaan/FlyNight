# Проверить восстановление пропусков по маскам — LTR

[[Обзор проекта/Запланировано|Запланировано]]

Собственная масочная ветвь и фиксированное правило поддержки обнаружением уже проверены; их итоги находятся в задаче восстановления. Точная LTR остаётся отдельной непроверенной работой: для её воспроизведения не подтверждены код и веса обученного выбора маски. Не требуется повторять готовые прогоны ради этого пункта.
