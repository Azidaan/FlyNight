# Протокол единственной рамки и конкуренции ID

Актуальный черновик для согласования — [ПРОТОКОЛ_v2.md](ПРОТОКОЛ_v2.md), формальная версия — [protocol_v2.json](protocol_v2.json). Указатель версии: [CURRENT.json](CURRENT.json).

Протокол подготовлен, опыт не зарегистрирован и не запущен. До запуска нужны исполняемая правка, экспорт отрицательных запросов и историй конкурентов, проверка кэшей и отдельное поручение автора.

Первая версия [ПРОТОКОЛ.md](ПРОТОКОЛ.md) и [protocol.json](protocol.json) сохранена как история подготовки; она заменена до расчётов. Во второй версии добавлено обязательное сравнение FlyVis с исходным трекером и усилен контроль вреда. Восемь вариантов и восемь основных сравнений не являются восемью запущенными опытами.

[queries.json](queries.json) содержит только причинные привязки 1991 архивного запроса. Метки вынесены отдельно в [evaluation_strata.json](evaluation_strata.json) и не разрешены для рабочего выбора.
